# VBR00387 — Set not permitted

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

Setting this property is not permitted.

MS-VBA run-time error 387; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 387` or `Error 387`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|Setting this property is not permitted.|assigning where the host refuses|Do not set it.|
