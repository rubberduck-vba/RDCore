# RDC01020: Undefined conditional constant

**Severity:** Hint &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `UndefinedConditionalConstantAnalyzer`

A `#If`, a `#ElseIf` or a `#Const` reads a conditional-compilation constant that nothing defines: no `#Const` of the module, no constant of the
project or of the command line, and no predefined constant.

Such a constant is `0`, as in MS-VBA, so a condition that tests it is `False`, and it is not an error. A misspelled name (`#If DEBGU Then`), or a
constant the project was meant to define, silently takes the other branch.

`Linux64` is a retired predefined constant: nothing defines it, and `Linux And Is64BitEnv` tests the same thing
([predefined constants](../specs/rd-vbal.2.3.1.2.session-services.md#bitness)).

The finding is the name, wherever a directive reads it.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A constant defined nowhere.|`#If DEV Then`|Define it: `#Const DEV = 1` in the module, or a constant of the project (`.rdproj`).|
|A misspelled constant.|`#If DEBGU Then`|Correct the name: `#If DEBUG Then`.|
|A retired predefined constant.|`#If Linux64 Then`|Test its replacement: `#If Linux And Is64BitEnv Then`.|

## Quick fix

The finding on a retired predefined constant comes with a quick fix, *Test Linux And Is64BitEnv*, which replaces the name, in parentheses where it is
the operand of an operator.
