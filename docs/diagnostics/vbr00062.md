# VBR00062 — Input past end of file

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A read goes past the end of the file.

MS-VBA run-time error 62; the numeric portion of the code is the error's number. This code is raised by [`FileStatementRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Statements.FileStatementRuntimeSemantics.html), [`InputListEvaluator`](../api/RDCore.Runtime.Execution.InputListEvaluator.html), [`StdHidden`](../api/RDCore.Runtime.StdLib.StdHidden.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A read goes past the end of the file.|`Input #1, x` or `Line Input #1, s` at the end|Test `EOF(1)` first.|
