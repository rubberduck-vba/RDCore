# VBR00096 — Unable to sink events of object because the object is already firing events to the maximum number of event receivers that it supports

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An object fires events to more receivers than it supports.

MS-VBA run-time error 96; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 96` or `Error 96`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An object fires events to more receivers than it supports.|an event with too many handlers|Detach handlers.|
