# VBR00746 — Replacements too long

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The replacement text is too long.

MS-VBA run-time error 746; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 746` or `Error 746`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The replacement text is too long.|a replace that would exceed the limit|Replace with less.|
