# VBC09387: Duplicate Option statement

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A module states an option directive more than once.

A module states each of `Option Compare`, `Option Base`, `Option Explicit` and `Option Private Module` at most once
([**MS-VBAL §5.2.1** Option Directives](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/049088bd-acb7-4e33-a875-ab17a891ccda)).
The value does not matter: `Option Base 1` after `Option Base 0` states `Option Base` twice, and so does `Option Compare Text` after
`Option Compare Binary`. The error is reported at each statement after the first, and the module does not load. MS-VBA reports the same error, with the
same message.

A directive stated in each branch of an `#If` block is stated once, whichever branch compiles. A directive in a branch that is not compiled is not part
of the module (**MS-VBAL §3.4**), so it does not count against the same option stated outside the block, or again in that branch.

This code is raised by `DeclarationStaticSemanticsEvaluator`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A module states an option twice.|`Option Explicit` on two lines of the module|Remove the second statement.|
|A module states an option twice, with two values.|`Option Base 0`, then `Option Base 1`|Keep the statement with the value the module needs.|
|A module states an option in a compiled branch of an `#If` block, and again outside the block.|`Option Explicit` in the `#If` branch, then after `#End If`|State it in every branch, or only outside the block.|
