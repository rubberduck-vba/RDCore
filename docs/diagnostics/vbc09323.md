# VBC09323 — Wrong number of arguments or invalid argument for event

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

The arguments of a `RaiseEvent` statement are not compatible with the parameter list of the event it raises.

[**MS-VBAL §5.4.2.20** RaiseEvent Statement](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/3795fff1-ce8a-40f7-8d2c-b1e2c1a251c4)
requires the event's parameter list to be compatible with the argument list according to the rules of procedure
invocation ([**MS-VBAL §5.3.1.11**](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/57cb1ccc-bf3d-4c07-a4ab-ecbb4cd7fcc7)),
all parameters and arguments being treated as positional.

This code is raised by
[`StatementStaticSemanticsEvaluator`](../api/RDCore.SDK.Semantics.Static.StatementStaticSemanticsEvaluator.html). The
verbose detail says how many arguments the event takes and how many were given.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|Fewer arguments than the event's required parameters.|`RaiseEvent Changed` for `Event Changed(ByVal Value As Long)`|Pass the argument: `RaiseEvent Changed(1)`.|
|More arguments than the event has parameters.|`RaiseEvent Closed(1)` for `Event Closed()`|Remove the extra argument, or declare the parameter on the event.|

An argument that cannot be Let-coerced to the type of a `ByVal` parameter is reported with the code of that coercion
(`VBC09310`, type mismatch), not with this one.

## Notes

Arguments are positional only: a `RaiseEvent` has no named arguments. An event's parameters do not define variables; they
describe the arguments the statement must provide, and the parameter list a handler must have.
