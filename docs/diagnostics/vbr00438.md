# VBR00438 — Object doesn't support this property or method

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An object does not have the property or method.

MS-VBA run-time error 438; the numeric portion of the code is the error's number. This code is raised by [`LetAssignmentEvaluator`](../api/RDCore.Runtime.Semantics.Statements.LetAssignmentEvaluator.html), [`ProcedureExecutor`](../api/RDCore.Runtime.Execution.ProcedureExecutor.html), [`RuntimeExpressionEvaluator`](../api/RDCore.Runtime.Semantics.RuntimeExpressionEvaluator.html), [`VBObjectLetCoercionRuntimeSemantics`](../api/RDCore.Runtime.Semantics.LetCoercion.VBObjectLetCoercionRuntimeSemantics.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An object does not have the property or method.|`obj.NoSuch`, a graphics method of an object that cannot draw|Call a member the object has.|
