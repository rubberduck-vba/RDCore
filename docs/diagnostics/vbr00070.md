# VBR00070: Permission denied

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

Access to a file or record is refused.

MS-VBA run-time error 70; the numeric portion of the code is the error's number. This code is raised by `ExternalCallPipeline`, `SessionFileChannels`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|Access to a file or record is refused.|`Open` for output a read-only file, a locked record|Change the permission, or wait for the lock.|
