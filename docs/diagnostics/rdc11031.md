# RDC11031: True value that is not -1

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `TrueValueIsNotMinusOneAnalyzer`

A condition reads a constant that stands for `True` with a number other than `-1`, such as `#Const DEV = 1`, through an operator that works on the bits
of the number. The condition does not mean what it says.

A condition is `True` when its value is not zero, so `#If DEV Then` with `DEV = 1` compiles its branch, as expected. The logical operators (`Not`, `And`,
`Xor`, `Eqv`, `Imp`) work on bits, though ([**MS-VBAL §5.6.9.8** Logical Operators](../specs/rd-vbal.5.6.9.8.logical-operators.md)), and `True` is
`-1`, every bit set. Any other number gives a different answer:

- `Not 1` is `-2`, which is `True`. `#If Not DEV Then` compiles the branch that was meant to be switched off.
- `1 = True` is `False`, because `True` is `-1`.
- `1 And 2` is `0`, which is `False`, although both numbers are `True` in a condition.
- `1 Xor True` is `-2`, which is `True`, although both operands are `True`.

MS-VBA evaluates these conditions this way, and so does RD-VBA. The fix is in the code: give the constant the value `True` (or `-1`), or test it with
`<> 0`.

## How it is raised

|Situation|Example|What happens|Resolution|
|---|---|---|---|
|`Not` of the constant.|`#Const DEV = 1`, then `#If Not DEV Then`|The branch is compiled: `Not 1` is `-2`.|`#Const DEV = True`|
|The constant compared with `True`.|`Const DEBUGGING = 1`, then `If DEBUGGING = True Then`|The condition is `False`.|`If DEBUGGING Then`, or `Const DEBUGGING = True`|
|`And` of two such constants with no bit in common.|`#Const A = 1`, `#Const B = 2`, then `#If A And B Then`|The branch is not compiled: `1 And 2` is `0`.|Give both the value `True`.|
|`Xor`, `Eqv` or `Imp` of the constant with a `Boolean`.|`#If DEV Xor Win64 Then`|The result is `True` or `False` for the wrong reason.|Give the constant the value `True`.|
|The value of a `#Const` made with such an operation.|`#Const RELEASE = Not DEV`|`RELEASE` is `-2`, which is `True`.|`#Const DEV = True`|

A condition that tests the constant by itself (`#If DEV Then`), `Or`, and a comparison with a number (`If DEV = 1 Then`) give the expected answer, and
are not reported. Neither is an operation with a variable that holds a number, such as `attributes And Not MASK`: the bits are what such code is about.
