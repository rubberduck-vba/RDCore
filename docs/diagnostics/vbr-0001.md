# VBR-0001 — Application-defined or object-defined error

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An error is raised with a number that has no message of its own, or by a member that cannot answer.

The error with no message of its own; the numeric portion of the code is the error's number. This code is raised by [`ExternalCallPipeline`](../api/RDCore.Runtime.Execution.External.ExternalCallPipeline.html), [`StdConversion`](../api/RDCore.Runtime.StdLib.StdConversion.html), [`StdHidden`](../api/RDCore.Runtime.StdLib.StdHidden.html), [`StdInformation`](../api/RDCore.Runtime.StdLib.StdInformation.html), [`StdLibDispatcher`](../api/RDCore.Runtime.StdLib.StdLibDispatcher.html), [`StdStrings`](../api/RDCore.Runtime.StdLib.StdStrings.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An error is raised with a number that has no message of its own, or by a member that cannot answer.|`Err.Raise 1000`|Give `Err.Raise` a description, or raise a number VBA defines.|
