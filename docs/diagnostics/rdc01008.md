# RDC01008: Native call reachable on every platform

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `NativeCallReachableOnEveryPlatformAnalyzer`

A `Declare` statement names a procedure of a library: `kernel32` is on Windows, `libc.dylib` on macOS, `libc.so.6` on Linux. No library is on every
platform, so a `Declare` that no `#If` on the platform constants (`Win32`, `Win64`, `Mac`, `Linux`, `Linux64`) makes dead calls its library where it
is not there. The call then raises run-time error 53 (*File not found*), or 453 (*Can't find DLL entry point*) where the library does not have the
procedure.

Every platform is considered, whichever one the code is analyzed on: the `#If` blocks of the module are evaluated once for each, with that platform's
predefined constants. A constant no platform decides (a `#Const` of the project or of the module, `DEBUG`, `VBA7`) has the value it has on every
platform, and so does a predefined constant the project or the module defines.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Declare` outside any `#If`, or in one that every platform makes live.|`Private Declare PtrSafe Function GetTickCount Lib "kernel32" () As Long`|Write it in a `#If` on the constant of the platform its library is on: `#If Win32 Then`.|
|A call of such a procedure, outside any `#If`.|`Debug.Print GetTickCount()`|Write the call in a `#If` too, with what the program does on the other platforms in its `#Else`.|
|A call compiled on a platform the procedure is not declared on.|The `Declare` in `#If Win32 Then`, the call outside it|Write the call in the same `#If` as the `Declare`.|

A call in a `#If` of its own is not reported: `#If Win32 Then` around a call of a procedure declared on every platform is the guard that matters.

A procedure written once in each branch of a `#If` on the platform constants (`#If Mac Then`, then `#Else`) is not reported either, and neither are its
calls: it is declared on every platform, each by the statement of its own branch, with that platform's library. Each statement is considered on its own:
in `#If VBA7 Then`, then `#Else`, the statement of the `VBA7` branch is compiled on every platform, and is reported.

## Quick fix

The finding on a `Declare` comes with a quick fix, *Write the Declare statement in #If … Then*, which writes `#If` before the statement and `#End If`
after it, with the statement's indentation. The constant is the one of the platform its library is of, as the name is written: `Mac` for a `.dylib` or
a framework, `Linux` for a `.so`, and `Win32`, which is true on 64-bit Windows too, for any other. The fix is not offered for a statement that shares a
line with another.

The calls of the procedure outside the new `#If` are reported then, as calls compiled where it is not declared.

## Notes

RD-VBA defines `Linux` and `Linux64`, which MS-VBA does not: a `Declare` in `#If Win32 Or Mac Then` is dead on Linux, and is not reported.
