# VBC09318 — With expression outside With block

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A member is written with a leading dot (`.Member` or `!Member`) where no enclosing `With` block supplies the object.

[**MS-VBAL §5.6.15** With Expressions](../specs/rd-vbal.5.6.15.with-expressions.md).

This code is raised by [`ExpressionStaticSemanticsEvaluator`](../api/RDCore.SDK.Semantics.Static.ExpressionStaticSemanticsEvaluator.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The leading dot has no `With` around it.|`.Name = "x"` outside any `With`|Write the object before the dot, or enclose the statement in a `With`.|
