# VBR00361 — Can't load or unload this object

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

`Load` or `Unload` is given an object that is no form.

MS-VBA run-time error 361; the numeric portion of the code is the error's number. `Load` and `Unload` load and unload a UserForm: any other object - a `Collection`, an instance of a class of the workspace - is one they cannot (Excel-measured).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|`Unload` is given an object that is no form.|`Unload New Collection`|Unload a form: `Unload UserForm1`, `Unload Me` in its code.|
|`Load` is given an object that is no form.|`Load New Collection`|Load a form, or create the object with `New` alone.|

A value that is no object at all - `Unload 5` - is not this error: it is a compile error, *Type mismatch*.
