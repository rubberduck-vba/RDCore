# VBR00459 — Object or class does not support the set of events.

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An object or class does not support the set of events.

MS-VBA run-time error 459; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 459` or `Error 459`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An object or class does not support the set of events.|`WithEvents` of an object that raises none of them|Use one that does.|
