# RDC00126: Indexed recursive default member access

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `IndexedRecursiveDefaultMemberAccessAnalyzer`

An argument list is given to an object of a known class whose default member takes no arguments. The default member is called with none, and the
arguments go to the default member of the object it returns
([**RD-VBAL §5.6.13** Index Expressions](../specs/rd-vbal.5.6.13.index-expressions.md)).

`rs("Name")`, with `rs` an ADO `Recordset`, calls `rs.Fields.Item("Name")`: two members, and the code names neither.

The finding is the whole expression.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An argument list that goes through a default member taking none.|`name = rs("Name")`|Name the members: `name = rs.Fields.Item("Name")`.|
|The same, assigned a value.|`rs("Name") = name`|Name the members: `rs.Fields.Item("Name") = name`.|
