# VBR00074 — Can't rename with different drive

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A file is renamed onto a different drive.

MS-VBA run-time error 74; the numeric portion of the code is the error's number. This code is raised by `SessionFileChannels`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A file is renamed onto a different drive.|`Name "C:\a" As "D:\a"`|Copy and delete.|
