# RDC00121: Indexed default member access

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `IndexedDefaultMemberAccessAnalyzer`

An argument list is given to an object of a known class, and its default member takes the arguments.

`items(1)`, with `items` a `Collection`, calls `items.Item(1)` ([**RD-VBAL §5.6.13** Index Expressions](../specs/rd-vbal.5.6.13.index-expressions.md)).
The code reads like an array, and the member it calls is hidden.

The finding is the whole expression.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An argument list given to an object.|`first = items(1)`|Name the member: `first = items.Item(1)`.|
