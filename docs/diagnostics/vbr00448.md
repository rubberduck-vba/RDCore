# VBR00448 — Named argument not found

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A named argument is not found.

MS-VBA run-time error 448; the numeric portion of the code is the error's number. This code is raised by [`RuntimeExpressionEvaluator`](../api/RDCore.Runtime.Semantics.RuntimeExpressionEvaluator.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A named argument is not found.|`Foo Nosuch:=1`|Name a parameter the procedure has.|
