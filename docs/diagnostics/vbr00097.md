# VBR00097 — Can not call friend function on object which is not an instance of defining class

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A `Friend` member is called on an object that is not an instance of the class that defines it.

MS-VBA run-time error 97; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 97` or `Error 97`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Friend` member is called on an object that is not an instance of the class that defines it.|a `Friend` call through another class's reference|Call it on an instance of its class.|
