# VBC09361 — ByRef argument type mismatch

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A variable is passed to a `ByRef` parameter of another type.

A `ByRef` parameter is another name for the variable passed to it, and is declared as a type: a variable of another type cannot be it. A `Variant` parameter takes a variable of any type.

MS-VBA reports the same error, with the same message (recorded in Excel).

This code is raised by [`ObjectValueStaticSemantics`](../api/RDCore.SDK.Semantics.Static.ObjectValueStaticSemantics.html), where the arguments of a call are matched to its parameters.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An `Integer` variable to a `ByRef Long` parameter.|`Dim i As Integer` … `TakesLong i`|Declare the variable as the parameter's type, declare the parameter `ByVal`, or pass the argument in parentheses: `TakesLong (i)`, a value that is copied.|
|A `Variant` variable to a `ByRef Long` parameter.|`Dim v As Variant` … `TakesLong v`|The same.|

## Notes

A member of an enumeration is a `Long`: a variable of an enumeration is passed to a `ByRef Long` parameter, and the other way around.
