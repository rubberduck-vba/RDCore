# VBC09332 — Exit Sub not allowed in Function or Property

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

An `Exit Sub` statement is in a `Function` or a property.

[**MS-VBAL §5.4.2.17** Exit Sub Statement](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/fe55464d-a2c4-4ca6-ace1-e757dbe95e73)
requires it to be inside the body of a subroutine. MS-VBA reports the same error:
[Exit Sub not allowed in Function or Property](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/exit-sub-not-allowed-in-function-or-property).

This code is raised by [`ExitStatementStaticSemantics`](../api/RDCore.SDK.Semantics.Static.ExitStatementStaticSemantics.html), which
[`StatementStaticSemanticsEvaluator`](../api/RDCore.SDK.Semantics.Static.StatementStaticSemanticsEvaluator.html) and instruction-list lowering
([`InstructionListLowering`](../api/RDCore.SDK.Semantics.Instructions.InstructionListLowering.html)) both ask, when they are told the kind of
procedure the statement is in.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|It is in a `Function`.|`Function Foo()` ... `Exit Sub`|Use `Exit Function`.|
|It is in a `Property Get`, `Property Let` or `Property Set`.|`Property Get Foo()` ... `Exit Sub`|Use `Exit Property`.|
