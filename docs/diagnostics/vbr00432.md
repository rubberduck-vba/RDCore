# VBR00432 — File name or class name not found during Automation operation

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A file or class name is not found during an Automation operation.

MS-VBA run-time error 432; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 432` or `Error 432`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A file or class name is not found during an Automation operation.|`GetObject("x.doc")` of a missing file|Name one that exists.|
