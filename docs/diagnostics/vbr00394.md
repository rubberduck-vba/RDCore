# VBR00394 — Get not supported (write-only property)

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A property is write-only.

MS-VBA run-time error 394; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 394` or `Error 394`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A property is write-only.|reading a write-only property|Do not read it.|
