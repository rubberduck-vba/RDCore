# RDC30002: More than one entry point

**Severity:** Error &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core, the builder) &nbsp;·&nbsp;
**Raised by:** `rdc run` and `rdc build`, before the program runs or is written

More than one standard module declares a `Sub Main`, and the build section of the `.rdproj` does not say which one the program starts at. The modules are
named on standard error, with this code. `rdc run` exits with code `2`, and `rdc build` writes no program.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|Two standard modules each declare a `Sub Main`, and the build section names no entry point.|`Program.bas` and `Tools.bas` both have a `Public Sub Main()`|Name the one to start at in the build section (`"entryPoint": "Program.Main"`), or rename the other.|
