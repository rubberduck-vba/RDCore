# VBR00005: Invalid procedure call or argument

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An argument is outside what a procedure accepts.

MS-VBA run-time error 5; the numeric portion of the code is the error's number. This code is raised by `BinaryArithmeticOperatorRuntimeSemantics`, `FileStatementRuntimeSemantics`, `IStdCollectionClass`, `IStdDateTimeModule`, `IStdInformationModule`, `IStdInteractionModule`, `LetCoercionRuntimeSemantics`, `MidStatementRuntimeSemantics`, `ProcedureExecutor`, `StdConversion`, `StdFileSystem`, `StdFinancial`, `StdHidden`, `StdLibDispatcher`, `StdCollection`, `StdEnumVariant`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An argument is outside what a procedure accepts.|`Mid("abc", 0)`, `Chr(-1)`|Pass a value the procedure documents.|
