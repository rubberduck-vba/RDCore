# VBR00005 — Invalid procedure call or argument

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An argument is outside what a procedure accepts.

MS-VBA run-time error 5; the numeric portion of the code is the error's number. This code is raised by [`BinaryArithmeticOperatorRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Operators.BinaryArithmeticOperatorRuntimeSemantics.html), [`FileStatementRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Statements.FileStatementRuntimeSemantics.html), [`IStdCollectionClass`](../api/RDCore.SDK.Runtime.Abstract.StdLib.IStdCollectionClass.html), [`IStdDateTimeModule`](../api/RDCore.SDK.Runtime.Abstract.StdLib.IStdDateTimeModule.html), [`IStdInformationModule`](../api/RDCore.SDK.Runtime.Abstract.StdLib.IStdInformationModule.html), [`IStdInteractionModule`](../api/RDCore.SDK.Runtime.Abstract.StdLib.IStdInteractionModule.html), [`LetCoercionRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Abstract.LetCoercionRuntimeSemantics.html), [`MidStatementRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Statements.MidStatementRuntimeSemantics.html), [`ProcedureExecutor`](../api/RDCore.Runtime.Execution.ProcedureExecutor.html), [`StdConversion`](../api/RDCore.Runtime.StdLib.StdConversion.html), [`StdFileSystem`](../api/RDCore.Runtime.StdLib.StdFileSystem.html), [`StdFinancial`](../api/RDCore.Runtime.StdLib.StdFinancial.html), [`StdHidden`](../api/RDCore.Runtime.StdLib.StdHidden.html), [`StdLibDispatcher`](../api/RDCore.Runtime.StdLib.StdLibDispatcher.html), `StdCollection`, `StdEnumVariant`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An argument is outside what a procedure accepts.|`Mid("abc", 0)`, `Chr(-1)`|Pass a value the procedure documents.|
