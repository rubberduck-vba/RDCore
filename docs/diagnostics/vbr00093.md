# VBR00093 — Invalid pattern string

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A `Like` pattern is not valid.

MS-VBA run-time error 93; the numeric portion of the code is the error's number. This code is raised by [`LikeRelationalOperatorRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Operators.Relational.LikeRelationalOperatorRuntimeSemantics.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Like` pattern is not valid.|`"a" Like "[a"`|Close the bracket.|
