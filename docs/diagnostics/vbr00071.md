# VBR00071 — Disk not ready

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The drive is not ready.

MS-VBA run-time error 71; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 71` or `Error 71`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The drive is not ready.|a read of an empty drive|Insert the medium.|
