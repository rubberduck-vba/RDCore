# VBR00067 — Too many files

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

There are no file numbers left.

MS-VBA run-time error 67; the numeric portion of the code is the error's number. This code is raised by [`StdFileSystem`](../api/RDCore.Runtime.StdLib.StdFileSystem.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|There are no file numbers left.|`FreeFile` with all 255 open|Close files you are done with.|
