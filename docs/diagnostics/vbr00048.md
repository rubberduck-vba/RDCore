# VBR00048 — Error in loading DLL

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A library named by a `Declare` cannot be loaded.

MS-VBA run-time error 48; the numeric portion of the code is the error's number. This code is raised by [`ExternalCallPipeline`](../api/RDCore.Runtime.Execution.External.ExternalCallPipeline.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A library named by a `Declare` cannot be loaded.|`Declare Sub F Lib "no-such" ()`|Name a library the host can load.|
