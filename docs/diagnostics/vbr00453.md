# VBR00453 — Specified DLL function not found

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A function named by a `Declare` is not found in the library.

MS-VBA run-time error 453; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 453` or `Error 453`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A function named by a `Declare` is not found in the library.|`Declare Sub F Lib "kernel32" Alias "nosuch" ()`|Name a function the library has.|
