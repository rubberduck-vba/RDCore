# VBR00455 — Code resource lock error

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A code resource cannot be locked.

MS-VBA run-time error 455; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 455` or `Error 455`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A code resource cannot be locked.|a locked code resource|Unlock it.|
