# VBR00061 — Disk full

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

There is no room left on the disk.

MS-VBA run-time error 61; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 61` or `Error 61`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|There is no room left on the disk.|a write to a full disk|Free space.|
