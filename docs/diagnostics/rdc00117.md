# RDC00117: Implicit constant type

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `ImplicitConstantTypeAnalyzer`

A constant states no type: it has no `As` clause and no type-declaration character.

A constant has a declared type all the same ([**RD-VBAL §5.2.3.2** Const Declarations](../specs/rd-vbal.5.2.3.module-declarations.md#5232-const-declarations)),
which the reader must work out from its value. An `As` clause states the type where the
constant is declared.

The finding is the name of the constant, of a module or of a procedure.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A constant with no `As` clause and no type character.|`Const myInteger = 12345`|`Const myInteger As Integer = 12345`|

A constant that states its type with a type character (`Const myInteger% = 12345`) is not reported; [RDC00307](rdc00307.md) reports the character.
