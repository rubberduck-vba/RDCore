# VBR00442 — Connection to type library or object library for remote process has been lost. Press OK for dialog to remove reference.

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The connection to a type library or object library is lost.

MS-VBA run-time error 442; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 442` or `Error 442`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The connection to a type library or object library is lost.|a remote reference after the server went away|Reconnect.|
