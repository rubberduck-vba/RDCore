# RDC00124: Unbound bang notation

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `UnboundBangNotationAnalyzer`

A dictionary access, `items!key`, of a variable declared `As Object`.

The `!` gives the name after it, as a `String`, to the default member of the object
([**RD-VBAL §5.6.14** Dictionary Access Expressions](../specs/rd-vbal.5.6.14.dictionary-access-expressions.md)), which is known only when the code runs.
An object whose class has no default member raises run-time error 438 (Object doesn't support this property or method).

The finding is the whole expression.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `!` name of an `Object`.|`Dim fields As Object`<br>`price = fields!Price`|`price = fields.Item("Price")`; or declare the variable with its class.|
