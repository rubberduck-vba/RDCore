# VBR00017 — Can't perform requested operation

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An operation is not possible in the state the session is in.

MS-VBA run-time error 17; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 17` or `Error 17`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An operation is not possible in the state the session is in.|`Err.Raise 17`|Do it where it is possible.|
