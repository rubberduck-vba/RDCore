# VBR00092 — For loop not initialized

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A loop is run from the middle, or a `For Each` array was never dimensioned.

MS-VBA run-time error 92; the numeric portion of the code is the error's number. This code is raised by [`ProcedureExecutor`](../api/RDCore.Runtime.Execution.ProcedureExecutor.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A loop is run from the middle, or a `For Each` array was never dimensioned.|`GoTo` to the line of a `Next`|Enter a loop through its opener.|
