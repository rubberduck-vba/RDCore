# VBR00445 — Object doesn't support this action

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An object does not support the action.

MS-VBA run-time error 445; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 445` or `Error 445`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An object does not support the action.|an action the object refuses|Do something it supports.|
