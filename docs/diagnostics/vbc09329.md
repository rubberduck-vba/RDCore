# VBC09329 — Object module needs to implement all members of its interface

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A class module that implements an interface does not declare the implemented name that corresponds to one of the
interface's public variables or methods.

[**MS-VBAL §5.2.4.2** Implements Directive](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/da526020-9b41-44a6-a5f3-47a7ac255a9e)
requires an implemented name declaration, named `InterfaceName_MemberName`, for each public method of the interface class, and for
each public variable the property declarations its declared type calls for.

This code is raised by
[`ImplementsSemantics`](../api/RDCore.SDK.Semantics.Static.ImplementsSemantics.html). The verbose detail names the member and the
declaration the module is missing.

## How it is raised

|Interface member|What the module must declare|
|---|---|
|`Public Sub Draw()`|`Sub IShape_Draw()`|
|`Public Function Area() As Double`|`Function IShape_Area() As Double`|
|`Public Property Get`, `Let` or `Set`|The same accessor, with the same name prefix|
|A public variable that is a `Variant`|A `Property Get`, a `Property Let` and a `Property Set`|
|A public variable that is an `Object` or a class|A `Property Get` and a `Property Set`|
|A public variable of any other type|A `Property Get` and a `Property Let`|

## Notes

A `Private` member of the interface is not part of what is implemented, and is not required. A member the module does declare, but
wrongly, is not reported as missing: what is wrong with it is [VBC09330](vbc09330.md).

The `Class` interface that every class module implements ([**RD-VBAL §5.3.1.10**](../specs/rd-vbal.5.3.1.10.lifecycle-handler-declarations.md))
requires nothing: each of its members has an implementation of its own.
