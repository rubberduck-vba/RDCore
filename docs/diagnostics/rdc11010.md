# RDC11010: Unresolved late-bound member access

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `UnresolvedLateBoundMemberAccessAnalyzer`

A member of an `Object` or a `Variant` is accessed, and no class the object can be of has a member of that name that the code can reach.

The member of an `Object` or a `Variant` is looked up when the code runs, in the class of the object it holds then
([**MS-VBAL §5.6.12** Member Access Expressions](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/af3a4059-3059-4e79-8aa5-685324fb266a)).
When the module's `Set` statements give the variable objects of known classes, and nothing else can assign it, those are the only classes it can hold. If
none of them has a `Public` member of the name (or a `Friend` one, from code of its own project), the access raises run-time error 438 (Object doesn't
support this property or method) whenever it runs. MS-VBA compiles it all the same.

A class of the VBA library (`Collection`) is looked up the same way: MS-VBA compiles `c.Nope` of a `Collection`. An object of such a class has the
members its class declares and no others, so a member it does not declare raises 438 whenever the code runs.

The finding is the member access.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A member that no class the variable is given has.|`Dim o As Object` / `Set o = New Holder` / `o.Nope`|Correct the name, or declare the variable as the class (`Dim o As Holder`), which makes the name a compile error until it is right.|
|A `Private` member of the class.|`Set o = New Holder` / `x = o.Secret`, where `Secret` is `Private`|Make the member `Public`, or access a `Public` member that uses it.|
|A member of an interface the class implements.|`Set o = New Square` / `x = o.Area`, where `Square` implements `IShape` with `IShape_Area`|Access it through a variable declared as the interface (`Dim s As IShape`).|
|A member that a class of the VBA library does not declare.|`Dim c As New Collection` / `c.Nope`|Correct the name.|

## Notes

An object given as an argument, held in a `Public` variable, returned by a function, read from a collection, or assigned from a variable of a class that
another class implements can be of any class: its access is not reported.

An object of a class of another library (`ws.Rnage` of an Excel `Worksheet`) or of a class module with `Attribute VB_Extensible = True` can have members
its class does not declare: the host or the object adds them. Its access is not reported here; a member that another library's class does not
declare is [RDC11051](rdc11051.md).
