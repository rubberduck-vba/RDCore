# VBC09313 — Exit For not within For...Next

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

An `Exit For` statement is not lexically inside a `For` or a `For Each` loop.

[**MS-VBAL §5.4.2.5** Exit For Statement](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/aa978e90-6240-454c-a7af-0a3e80779dc7)
requires it to be inside a `For` or a `For Each` statement, at any depth; MS-VBA reports the same error:
[Exit For not within For...Next](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/exit-for-not-within-fornext).

This code is raised by [`ExitStatementStaticSemantics`](../api/RDCore.SDK.Semantics.Static.ExitStatementStaticSemantics.html), which
[`StatementStaticSemanticsEvaluator`](../api/RDCore.SDK.Semantics.Static.StatementStaticSemanticsEvaluator.html) and instruction-list lowering
([`InstructionListLowering`](../api/RDCore.SDK.Semantics.Instructions.InstructionListLowering.html)) both ask.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|There is no loop around the statement.|`Exit For` in the body of a `Sub`|Remove it, or use `Exit Sub`, `Exit Function` or `Exit Property` to leave the procedure.|
|The loops around it are not `For` loops.|`Do` ... `Exit For` ... `Loop`|Use `Exit Do` to leave a `Do` loop.|
|It is in a `While...Wend` loop.|`While x` ... `Exit For` ... `Wend`|`While...Wend` has no `Exit` statement. Use a `Do While` loop.|
