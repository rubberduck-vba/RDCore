# VBR00744 — Search text not found

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The text searched for is not found.

MS-VBA run-time error 744; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 744` or `Error 744`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The text searched for is not found.|a find that matches nothing|Search for text that is there.|
