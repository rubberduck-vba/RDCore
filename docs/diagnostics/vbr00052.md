# VBR00052 — Bad file name or number

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A file number is not valid, or is not open.

MS-VBA run-time error 52; the numeric portion of the code is the error's number. This code is raised by [`FileStatementRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Statements.FileStatementRuntimeSemantics.html), [`StdHidden`](../api/RDCore.Runtime.StdLib.StdHidden.html), `SessionFileChannels`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A file number is not valid, or is not open.|`Print #1, x` before `Open`, `Close #300`|Use a number from `FreeFile`, and open it first.|
