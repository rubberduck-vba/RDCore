# VBC09302 — Variable not defined

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A name is used that no declaration defines, in a module that states `Option Explicit`.

Without `Option Explicit` an undeclared name declares a variable where it is used ([**MS-VBAL §5.6.10**](../specs/rd-vbal.5.6.10.simple-name-expressions.md)); with it, it is this error. MS-VBA reports the same error: [Variable not defined](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/variable-not-defined).

This code is raised by [`SimpleNameExpressionStaticSemantics`](../api/RDCore.SDK.Semantics.Static.Expressions.SimpleNameExpressionStaticSemantics.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A name is used that is declared nowhere.|`Option Explicit` ... `Total = 1` with no `Dim Total`|Declare it, or correct the spelling.|
