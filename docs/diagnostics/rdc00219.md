# RDC00219: Unreachable Case

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `UnreachableCaseAnalyzer`

A `Case` block, or the `Case Else` block, of a `Select Case` statement can never run: no value of the selector reaches it.

`Select Case` tries its `Case` blocks in order and runs the first one whose clause matches the selector
([**MS-VBAL §5.4.2.10** Select Case Statement](../specs/rd-vbal.5.4.2.10.select-case-statement.md)). A block whose clauses match only values that the
blocks before it already match never runs. Neither does a `Case Else` after blocks that match every value of the selector's type, nor a block whose
ranges each start above where they end (`Case 10 To 1` matches nothing).

The selector is read by its declared type: `Byte`, `Integer`, `Long`, `LongLong`, an `Enum` (whose values are those of a `Long`), or `Boolean`. A clause is
counted when its values are numbers or constants of a whole-number type that the selector's type holds, such as `5`, `-5`, `Limit` or an `Enum` member,
and, for a `Boolean` selector, `True` or `False`. Any other clause, such as `5.4`, `"5"` or a variable, is converted to the selector's type first, or is
known only when the code runs, and is not counted. A block with such a clause is reported only when the blocks before it match every value of the type.
Nothing is reported for a selector of another type.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The blocks before it match every value it matches.|`Case 0 To 99` … `Case 50`|Remove the block, or move it before the block that matches its values.|
|The blocks before it match every value of the selector's type.|`Case Is < 100` … `Case Is > -100` … `Case 5`|Remove the block, or narrow the clauses before it.|
|Its range starts above where it ends.|`Case 10 To 1`|Write the smaller value first: `Case 1 To 10`.|
|A `Case Else` after blocks that match every value of the selector's type.|`Case True` … `Case False` … `Case Else`|Remove the `Case Else` block.|
