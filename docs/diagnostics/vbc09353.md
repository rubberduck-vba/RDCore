# VBC09353 — Division by zero

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

The value of a constant divides by zero.

A constant is evaluated before the code runs, and a division by zero is refused then, where an expression of variables would raise error 11 when the code runs.

MS-VBA reports the same error, with the same message (recorded in Excel).

This code is raised by the host, when it evaluates the constants of a module it loads.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A division by zero.|`Const k = 1 / 0`|Correct the value.|
