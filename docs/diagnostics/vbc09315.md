# VBC09315 — Exit Property not allowed in Sub or Function

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

An `Exit Property` statement is in a `Sub` or a `Function`.

[**MS-VBAL §5.4.2.19** Exit Property Statement](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/2c254f33-48b5-40b7-9dc7-4943313a1742)
requires it to be inside the body of a property declaration. MS-VBA reports the same error:
[Exit Property not allowed in Function or Sub](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/exit-property-not-allowed-in-function-or-sub).

This code is raised by [`ExitStatementStaticSemantics`](../api/RDCore.SDK.Semantics.Static.ExitStatementStaticSemantics.html), which
[`StatementStaticSemanticsEvaluator`](../api/RDCore.SDK.Semantics.Static.StatementStaticSemanticsEvaluator.html) and instruction-list lowering
([`InstructionListLowering`](../api/RDCore.SDK.Semantics.Instructions.InstructionListLowering.html)) both ask, when they are told the kind of
procedure the statement is in.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|It is in a `Sub`.|`Sub Foo()` ... `Exit Property`|Use `Exit Sub`.|
|It is in a `Function`.|`Function Foo()` ... `Exit Property`|Use `Exit Function`.|
