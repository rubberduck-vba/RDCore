# VBR00013 — Type mismatch

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A value cannot be coerced to the type that is required.

MS-VBA run-time error 13; the numeric portion of the code is the error's number. ## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A value cannot be coerced to the type that is required.|`"abc" + 1`, `CLng("x")`, `For Each` over a scalar|Convert with a function that accepts the value, or fix the type.|
