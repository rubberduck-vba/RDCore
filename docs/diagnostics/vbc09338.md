# VBC09338: Cannot define a Public user-defined type within an object module

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A class module declares a user-defined type that is public: a `Public Type`, or a `Type` declared with no modifier, which is public.

A user-defined type of a class module is private to it. The class names it from within, by its name or through the name of the class (`Dim t As Shapes.TState`); another module cannot name it at all. A type that other modules use is declared in a standard module. An `Enum` of a class module may be public.

MS-VBA reports the same error: _Cannot define a Public user-defined type within an object module_.

This code is raised by [PublicMemberSemantics](../api/RDCore.SDK.Semantics.Static.PublicMemberSemantics.html), at the type.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Public Type` in a class module.|`Public Type TState` … `End Type`|Declare it `Private`, or move it to a standard module.|
|A `Type` with no modifier in a class module.|`Type TState` … `End Type`|The same.|
