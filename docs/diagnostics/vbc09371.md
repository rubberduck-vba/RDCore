# VBC09371 — Array argument must be ByRef

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

An argument of an array parameter is written `ByVal`.

An array parameter (`a() As Long`) is always `ByRef`: the procedure is given the array itself, never a copy of it, so an array cannot be passed by value.
`ByVal` written before the argument asks for what the parameter cannot take.

MS-VBA reports the same error, with the same message (recorded in Excel).

This code is raised where a call is checked, at the argument written `ByVal`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An array given `ByVal` to an array parameter.|`Sub Bump(a() As Long)` … `Bump ByVal values`|Remove `ByVal`: the procedure works on the array. To work on a copy, copy it first: `Dim copy() As Long: copy = values`.|
