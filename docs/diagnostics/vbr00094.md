# VBR00094 — Invalid use of Null

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

`Null` is used where it is not allowed.

MS-VBA run-time error 94; the numeric portion of the code is the error's number. This code is raised by [`LetCoercionRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Abstract.LetCoercionRuntimeSemantics.html), [`StdConversion`](../api/RDCore.Runtime.StdLib.StdConversion.html), [`StdFinancial`](../api/RDCore.Runtime.StdLib.StdFinancial.html), [`ValueConversionResult`](../api/RDCore.Runtime.Semantics.Conversion.ValueConversionResult.html), [`ValueConversions`](../api/RDCore.Runtime.Semantics.Conversion.ValueConversions.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|`Null` is used where it is not allowed.|`Left$(Null, 1)`|Test `IsNull` first.|
