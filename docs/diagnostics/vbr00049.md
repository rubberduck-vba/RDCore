# VBR00049 — Bad DLL calling convention

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A `Declare`d procedure is called with a convention it does not have.

MS-VBA run-time error 49; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 49` or `Error 49`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Declare`d procedure is called with a convention it does not have.|`Declare` call with the wrong argument stack|Match the declaration to the library.|
