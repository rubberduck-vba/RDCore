# RDC01022: Assignment not used

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `AssignmentNotUsedAnalyzer`

A local variable or a `ByVal` parameter is assigned a value that nothing reads: on every code path, another assignment replaces it, or the procedure
ends, first.

The assignment has no effect on what the procedure does, other than evaluating its value. It is often left over from a change, or a sign that the code
reads the wrong variable.

Code that runs in another procedure counts: a call made between the assignment and the next one may read a variable that both procedures can see.

Not reported:

- `Set x = Nothing`, which releases the object where the code says so;
- an assignment to an array;
- an assignment to a `ByRef` parameter, which assigns the caller's variable.

The finding is the name of the variable in the assignment.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A value is replaced before it is read.|`total = 0`<br>`total = Count()`|Remove the first assignment, if evaluating its value is not needed.|
|A value is assigned and the procedure ends.|`Dim result As Long`<br>`result = Compute()`<br>`End Sub`|Remove the assignment, or use the value.|
