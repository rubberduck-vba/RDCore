# VBR00450: Wrong number of arguments or invalid property assignment

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The number of arguments is wrong, or a property assignment is invalid.

MS-VBA run-time error 450; the numeric portion of the code is the error's number. This code is raised by `RuntimeExpressionEvaluator`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The number of arguments is wrong, or a property assignment is invalid.|`Foo 1, 2` where `Foo` takes one|Pass the arguments the member takes.|
|A call statement names a property of an object declared `As Object` or `Variant`. The `Property Get` is not called.|`o.Value`, `o.Item 1`|Use the property's value (`x = o.Value`), or call a `Sub` or a `Function`.|
