# VBR00450 — Wrong number of arguments or invalid property assignment

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The number of arguments is wrong, or a property assignment is invalid.

MS-VBA run-time error 450; the numeric portion of the code is the error's number. This code is raised by [`RuntimeExpressionEvaluator`](../api/RDCore.Runtime.Semantics.RuntimeExpressionEvaluator.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The number of arguments is wrong, or a property assignment is invalid.|`Foo 1, 2` where `Foo` takes one|Pass the arguments the member takes.|
