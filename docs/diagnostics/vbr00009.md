# VBR00009: Subscript out of range

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An index is outside the bounds of an array, or a collection has no such item.

MS-VBA run-time error 9; the numeric portion of the code is the error's number. This code is raised by `ArrayBoundRuntimeSemantics`, `ArrayStatementRuntimeSemantics`, `LetAssignmentEvaluator`, `RuntimeExpressionEvaluator`, `StdCollection`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An index is outside the bounds of an array, or a collection has no such item.|`a(11)` of `Dim a(1 To 10)`, `c(5)` of a collection of three|Index from `LBound` to `UBound`.|
