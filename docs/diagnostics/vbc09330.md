# VBC09330 — Invalid implemented member

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A procedure named for a member of an implemented interface, `InterfaceName_MemberName`, does not correspond to that member.

[**MS-VBAL §5.3.1.9** Implemented Name Declarations](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/9e68b3a3-7c21-47ba-8621-2d03aebd83cf)
gives what it must be: the kind of declaration its member is, with an equivalent parameter list, and the same type.

This code is raised by
[`ImplementsSemantics`](../api/RDCore.SDK.Semantics.Static.ImplementsSemantics.html). The verbose detail names the
declaration, the member and what is different.

## How it is raised

|Situation|Example, for `Public Function Area(ByVal Scale As Double) As Double`|Resolution|
|---|---|---|
|It is another kind of declaration.|`Sub IShape_Area(ByVal Scale As Double)`|Declare a function. A subroutine is implemented by a subroutine, and each property accessor by the same accessor.|
|The member is a variable, and this is not a property.|`Sub IShape_Title()`, for `Public Title As String`|Declare `Property Get`, and `Property Let` or `Set`.|
|It has another number of parameters, or an `Optional` or a `ParamArray` that the member does not have, or the member has one it does not.|`Function IShape_Area() As Double`|Declare the member's parameters.|
|A parameter is of another type, or passed by another mechanism.|`(ByRef Scale As Double)`|Declare the member's type and mechanism.|
|The function, the `Property Get`, or the value of a `Property Let` or `Set` is of another type than the member's.|`Function IShape_Area(ByVal Scale As Double) As Long`|Declare the member's type.|

## Notes

The parameters may differ in their names, and in whether the mechanism is written out: `Count As Long` implements `ByRef Count As Long`.

A procedure that begins with an interface's prefix but is not named for one of its members is not an implemented name declaration of anything,
and is not checked.

The default value of an `Optional` parameter must be the same constant; only a literal default is compared.
