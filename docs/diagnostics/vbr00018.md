# VBR00018 — User interrupt occurred

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The program is interrupted.

MS-VBA run-time error 18; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 18` or `Error 18`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The program is interrupted.|`Err.Raise 18`|Break and `Stop` are not errors here: they stop the program where it is.|
