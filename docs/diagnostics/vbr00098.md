# VBR00098 — A property or method call cannot include a reference to a private object, either as an argument or as a return value

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A public call includes a reference to a private object.

MS-VBA run-time error 98; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 98` or `Error 98`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A public call includes a reference to a private object.|passing a private-class object to a public method|Make the type public, or do not expose it.|
