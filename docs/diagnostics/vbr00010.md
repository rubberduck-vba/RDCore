# VBR00010 — This array is fixed or temporarily locked

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An array that is fixed-size or locked is resized or erased.

MS-VBA run-time error 10; the numeric portion of the code is the error's number. This code is raised by [`ArrayStatementRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Statements.ArrayStatementRuntimeSemantics.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An array that is fixed-size or locked is resized or erased.|`ReDim` of an array a procedure is using by reference|Use a dynamic array, and resize it where nothing holds it.|
