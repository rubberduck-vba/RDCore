# VBR00068 — Device unavailable

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The device is not available.

MS-VBA run-time error 68; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 68` or `Error 68`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The device is not available.|`Open "LPT1" For Output As #1` with no printer|Use a device that exists.|
