# VBC00044 — For without Next

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (parser / concrete syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBSyntaxErrorInfo`](../api/RDCore.SDK.Model.Errors.VBSyntaxErrorInfo.html)

A `For` loop is not ended before its procedure is.

A `For` or `For Each` loop is ended by a `Next` statement in the same procedure.

MS-VBA reports the same error, with the same message (recorded in Excel).

This code is raised by the parser, at the statement that does not fit, when the grammar refuses a procedure whose blocks do not match. RD-VBA reports it for every procedure; MS-VBA stops at the first.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A loop with no `Next`.|`For i = 1 To 2` … `End Sub`|Write `Next` where the loop ends.|
