# RDC11039: Function called whatever the IIf condition

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `IIfSideEffectAnalyzer`

A `Function` or a `Property Get` is called in the `TruePart` or the `FalsePart` of `IIf`.

`IIf` is a function of the VBA library ([**MS-VBAL §6.1.2.8.1.11** IIf](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/3593c073-c770-4060-8416-aaf7545ea5fe)).
Like the arguments of any call, its three arguments are evaluated before it is called. Both the `TruePart` and the `FalsePart` are evaluated, whatever
the condition: a function called in either of them runs every time, with whatever it changes and whatever error it raises.

Calls to the functions of the VBA library that change nothing and raise no error for an argument of the type they declare are not reported: `Len`,
`Trim`, `UCase`, `IsNumeric`, `TypeName`, `Now` and the like. A call that is bound only when the code runs is not reported either.

The finding is the name of the function called.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A function of the project in the `TruePart` or `FalsePart`.|`x = IIf(divisor <> 0, Quotient(a, divisor), 0)`|Use an `If` statement, which runs only the branch the condition chooses.|
|A function of a library that can raise an error or has an effect.|`IIf(ok, CLng(text), MsgBox("Not a number"))`|Same: an `If` statement.|
|A function in a part given as a named argument.|`IIf(c, FalsePart:=Count(), TruePart:=0)`|Same.|
