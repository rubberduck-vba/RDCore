# RDC01019: Win64 is a bitness test

**Severity:** Hint &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `Win64IsABitnessTestAnalyzer`

A `#If`, a `#ElseIf` or a `#Const` reads the predefined constant `Win64`.

`Win64` is `1` in a 64-bit environment on Windows, and on a 64-bit Mac too, as in Excel for Mac, where `Win32` is `0`. Code that tests `Win64` to mean
"64-bit Windows" compiles its Windows branch on a Mac: a `Declare` of a Windows library is compiled there, and its call raises run-time error 53
(*File not found*). On Linux, `Win64` is `0`, so a branch meant for any 64-bit environment is dead there.

`Is64BitEnv` is `1` in a 64-bit environment, on any operating system. It is the constant to test for the width of a pointer, and `Win32 And Is64BitEnv`
tests for 64-bit Windows.

The finding is the name `Win64`. It is not raised when the module declares its own `#Const Win64`, or when the platform sets `Win64` on 64-bit Windows
only (`Environment.Win64OnlySetOnWindows`).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A condition on the bitness of the environment.|`#If Win64 Then`<br>`    Dim Handle As LongLong`<br>`#Else`<br>`    Dim Handle As Long`<br>`#End If`|Test `Is64BitEnv`: `#If Is64BitEnv Then`.|
|A condition on 64-bit Windows.|`#If Win64 Then`<br>`    Private Declare PtrSafe Function GetWindowLongPtrA Lib "user32" (ByVal hWnd As LongPtr, ByVal nIndex As Long) As LongPtr`|Test `Win32 And Is64BitEnv`: `#If Win32 And Is64BitEnv Then`.|
|`Win64` as an operand.|`#If VBA7 And Win64 Then`|The same fixes, the second in parentheses: `#If VBA7 And Is64BitEnv Then`, or `#If VBA7 And (Win32 And Is64BitEnv) Then`.|

## Quick fix

The diagnostic comes with two quick fixes: *Test Is64BitEnv*, and *Test Win32 And Is64BitEnv*. Each replaces the name. The second is written in
parentheses where the name is the operand of an operator.
