# VBR00430 — Class does not support Automation or does not support expected interface

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A class does not support Automation or the interface expected.

MS-VBA run-time error 430; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 430` or `Error 430`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A class does not support Automation or the interface expected.|`New` of a class that is not creatable|Use a class that is.|
