# VBR00458 — Variable uses an Automation type not supported in Visual Basic

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A variable uses an Automation type that Visual Basic does not support.

MS-VBA run-time error 458; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 458` or `Error 458`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A variable uses an Automation type that Visual Basic does not support.|a call with a type VBA cannot hold|Use a supported type.|
