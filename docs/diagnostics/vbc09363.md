# VBC09363 — Expected variable or procedure, not module

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

The name of a standard module is used by itself, as a value or a procedure.

A standard module's name qualifies the names of its members (`Globals.Counter`): by itself it is no variable, no value and no procedure.

MS-VBA reports the same error, with the same message (recorded in Excel).

This code is raised by [`SimpleNameExpressionStaticSemantics`](../api/RDCore.SDK.Semantics.Static.Expressions.SimpleNameExpressionStaticSemantics.html), where a name is resolved.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A module assigned to a variable.|`x = Globals`|Name the member of the module: `x = Globals.Counter`.|
|A module called.|`Call Globals`|Name the procedure of the module: `Call Globals.Reset`.|
