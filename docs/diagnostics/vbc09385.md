# VBC09385: Not a legal object name

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A module is named with a keyword of the language.

A module's name is the one its `Attribute VB_Name` line says, or its file's name when it has none. The name is an identifier (**MS-VBAL §4.2**), and no
reserved identifier is one
([**MS-VBAL §3.3.5.2** Reserved Identifiers and IDENTIFIER](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/e1ac8be4-9b8d-4a4c-a1a4-6cc4ecba6b95)).
MS-VBA refuses to rename a module to such a name, or to import a standard module that has one, with the message "Not a legal object name". The module
does not load, and a program that has it does not run.

A reserved type identifier that is not a reserved name, such as `Long` or `Integer`, is an identifier: the module compiles, with the warning
[RDC11034](rdc11034.md).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A module's `VB_Name` is a keyword.|`Attribute VB_Name = "Circle"`|Give the module another name, such as `Circles`.|
|A module that has no `VB_Name` is in a file named with a keyword.|`Dim.bas`|Add an `Attribute VB_Name` line with another name, or rename the file.|
|A class module's `VB_Name` is a keyword.|`Attribute VB_Name = "Debug"`|Give the class another name, such as `DebugLog`.|
