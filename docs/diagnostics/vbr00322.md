# VBR00322 — Can't create necessary temporary file

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A temporary file the operation needs cannot be created.

MS-VBA run-time error 322; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 322` or `Error 322`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A temporary file the operation needs cannot be created.|a save with no writable temporary directory|Make one writable.|
