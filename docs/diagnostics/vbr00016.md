# VBR00016 — Expression too complex

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An expression is nested too deeply to evaluate.

MS-VBA run-time error 16; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 16` or `Error 16`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An expression is nested too deeply to evaluate.|a long chain of nested parentheses|Split the expression.|
