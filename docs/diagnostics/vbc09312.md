# VBC09312 — Exit Do not within Do...Loop

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

An `Exit Do` statement is not lexically inside a `Do` loop.

[**MS-VBAL §5.4.2.7** Exit Do Statement](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/f672b312-fe2a-4f4d-9ad4-42729b110fe7)
requires it to be inside a `Do` statement, at any depth; MS-VBA reports the same error:
[Exit Do not within Do...Loop](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/exit-do-not-within-doloop).

This code is raised by [`ExitStatementStaticSemantics`](../api/RDCore.SDK.Semantics.Static.ExitStatementStaticSemantics.html), which
[`StatementStaticSemanticsEvaluator`](../api/RDCore.SDK.Semantics.Static.StatementStaticSemanticsEvaluator.html) and instruction-list lowering
([`InstructionListLowering`](../api/RDCore.SDK.Semantics.Instructions.InstructionListLowering.html)) both ask.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|There is no loop around the statement.|`Exit Do` in the body of a `Sub`|Remove it, or use `Exit Sub`, `Exit Function` or `Exit Property` to leave the procedure.|
|The loops around it are not `Do` loops.|`For i = 1 To 3` ... `Exit Do` ... `Next`|Use `Exit For` to leave a `For` loop.|
|It is in a `While...Wend` loop.|`While x` ... `Exit Do` ... `Wend`|`While...Wend` has no `Exit` statement. Use a `Do While` loop.|

## Notes

An `Exit Do` is the closest enclosing `Do` loop's, so an `Exit Do` in a `Do` loop that is inside a `For` loop is valid, and so is an `Exit For` in a `Do` loop that is
inside a `For` loop.
