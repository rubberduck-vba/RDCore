# VBC00059 — You must terminate the #If block with an #EndIf

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (parser / concrete syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBSyntaxErrorInfo`](../api/RDCore.SDK.Model.Errors.VBSyntaxErrorInfo.html)

A `#If` block is not ended: the module ends before its `#End If`.

An `#End If` with text after it, other than a comment, is no directive, and ends nothing. `#EndIf`, written as one word, ends the block.

MS-VBA reports the same error, with the same message (recorded in Excel).

This code is raised by the parser, at the `#If` of each block that is not ended.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|No `#End If`.|`#If VBA7 Then` … (end of the module)|Write the `#End If` that ends the block.|
|Text after the `#End If`.|`#If Mac Then` … `#End If junk`|Remove the text, or make it a comment.|
