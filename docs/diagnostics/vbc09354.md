# VBC09354: Invalid qualifier

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A member is accessed on a value that has no members.

A number, a `String`, a `Boolean` or a `Date` is a value, with no members, and so is an array, fixed-size or resizable: only an object, a user-defined type, a module or an enumeration has members to access with a dot. A `Variant` compiles, whatever it holds: one that holds an array or a number when the member is read, assigned or called is run-time error 424, _Object required_.

MS-VBA reports the same error, with the same message (recorded in Excel).

This code is raised by [`MemberAccessExpressionStaticSemantics`](../api/RDCore.SDK.Semantics.Static.Expressions.MemberAccessExpressionStaticSemantics.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A member of a `Long`.|`Dim n As Long` … `Debug.Print n.Value`|Remove the member, or declare the variable as the class that has it.|
|A member of an array, read or assigned.|`Dim v(2) As Long` … `v.Foo = 1`, `Dim v() As Long` … `x = v.Foo`|Index the array first, `v(0)`, when its elements are objects or records; to count its elements, use `UBound(v) - LBound(v) + 1`.|
