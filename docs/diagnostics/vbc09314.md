# VBC09314 — Exit Function not allowed in Sub or Property

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

An `Exit Function` statement is in a `Sub`, or in a `Property Let` or a `Property Set`.

[**MS-VBAL §5.4.2.18** Exit Function Statement](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/d70e6f6f-b830-4be2-acce-aa491c8acb5a)
requires it to be inside the body of a function. MS-VBA reports the same error:
[Exit Function not allowed in Sub or Property](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/exit-function-not-allowed-in-sub-or-property).

This code is raised by [`ExitStatementStaticSemantics`](../api/RDCore.SDK.Semantics.Static.ExitStatementStaticSemantics.html), which
[`StatementStaticSemanticsEvaluator`](../api/RDCore.SDK.Semantics.Static.StatementStaticSemanticsEvaluator.html) and instruction-list lowering
([`InstructionListLowering`](../api/RDCore.SDK.Semantics.Instructions.InstructionListLowering.html)) both ask, when they are told the kind of
procedure the statement is in.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|It is in a `Sub`.|`Sub Foo()` ... `Exit Function`|Use `Exit Sub`.|
|It is in a `Property Let` or a `Property Set`.|`Property Let Foo(ByVal v As Long)` ... `Exit Function`|Use `Exit Property`.|

## Notes

An `Exit Function` in a `Property Get` is not reported. **MS-VBAL §5.4.2.18** says it must be in a function, but MS-VBA accepts it in a property getter, and a
program written against MS-VBA relies on that.
