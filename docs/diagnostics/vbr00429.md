# VBR00429: ActiveX component can't create object

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An ActiveX component cannot create the object.

MS-VBA run-time error 429; the numeric portion of the code is the error's number. This code is raised by `NewExpressionRuntimeSemantics`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An ActiveX component cannot create the object.|`CreateObject("No.Such")`|Install or register the component.|
