# VBC09325 — Invalid event name

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

The name of an `Event` declaration contains an underscore.

[**MS-VBAL §5.2.4.3** Event Declaration](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/ff9d44a9-7a89-474e-9546-a1b169d38a26)
forbids an underscore (`U+005F`) in the name of an event. An event is handled by a procedure named
`VariableName_EventName`, and the underscore is where the variable's name ends: a name with one in it would be ambiguous.

This code is raised by
[`ClassModuleEventSemantics`](../api/RDCore.SDK.Semantics.Static.ClassModuleEventSemantics.html). The verbose detail
names the event.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An event name has an underscore.|`Public Event Data_Changed()`|Rename the event without it: `Public Event DataChanged()`.|

## Notes

The same module may not declare two events of one name either, whatever the case; the second is reported as a duplicate
declaration (`VBC09303`).

An event name can be the name of a module variable, constant, enum member or procedure of the same module.
