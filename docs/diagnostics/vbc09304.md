# VBC09304 — Invalid use of object

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

An object is used where a value of another kind is required.

MS-VBA reports the same error: [Invalid use of object](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/invalid-use-of-object).

This code is raised by [`StatementStaticSemanticsEvaluator`](../api/RDCore.SDK.Semantics.Static.StatementStaticSemanticsEvaluator.html), [`PrecompilerLiveBranchEvaluator`](../api/RDCore.Runtime.Semantics.Precompiler.PrecompilerLiveBranchEvaluator.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The default instance variable of a class is the target of a `Set`.|`Set UserForm1 = Nothing`|Assign to a variable of your own.|
|A conditional-compilation expression is an object.|`#If Nothing Then`|A condition is a number or a `Boolean`.|
