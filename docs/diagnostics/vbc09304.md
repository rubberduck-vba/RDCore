# VBC09304 — Invalid use of object

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

An object is used where a value of another kind is required.

MS-VBA reports the same error: [Invalid use of object](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/invalid-use-of-object).

This code is raised by [`ObjectValueStaticSemantics`](../api/RDCore.SDK.Semantics.Static.ObjectValueStaticSemantics.html), [`PrecompilerLiveBranchEvaluator`](../api/RDCore.Runtime.Semantics.Precompiler.PrecompilerLiveBranchEvaluator.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The `Nothing` literal is where a value is expected: assigned to a variable of a value type, an operand, an argument of a parameter of a value type or of a function that reads a value ([**RD-VBAL §5.5.1.1**](../specs/rd-vbal.5.5.1.1.static-semantics.md)).|`n = Nothing`, `If x = Nothing Then`, `CStr(Nothing)`|`Nothing` has no value: to clear an object variable, `Set` it to `Nothing`; to test one, use `Is Nothing`.|
|A conditional-compilation expression is an object.|`#If Nothing Then`|A condition is a number or a `Boolean`.|
