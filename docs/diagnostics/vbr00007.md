# VBR00007 — Out of memory

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The session's memory cannot hold an allocation.

MS-VBA run-time error 7; the numeric portion of the code is the error's number. This code is raised by [`CallStackFrame`](../api/RDCore.Runtime.Execution.Frames.CallStackFrame.html), [`RuntimeSymbolResolver`](../api/RDCore.Runtime.Execution.RuntimeSymbolResolver.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The session's memory cannot hold an allocation.|`ReDim a(0 To 2147483646)`|Allocate less.|
