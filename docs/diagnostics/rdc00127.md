# RDC00127: Recursive bang notation

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `RecursiveBangNotationAnalyzer`

A dictionary access, `rs!key`, of an object of a known class whose default member takes no arguments.

The `!` gives the name after it, as a `String`, to the default member of the object
([**RD-VBAL §5.6.14** Dictionary Access Expressions](../specs/rd-vbal.5.6.14.dictionary-access-expressions.md)). That member takes none: it is called
with none, and the name goes to the default member of the object it returns
([**RD-VBAL §5.6.13** Index Expressions](../specs/rd-vbal.5.6.13.index-expressions.md)). `rs!Name`, with `rs` an ADO `Recordset`, is
`rs.Fields.Item("Name")`.

The finding is the whole expression.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `!` name that goes through a default member taking none.|`name = rs!Name`|Name the members and pass the string: `name = rs.Fields.Item("Name")`.|

## Quick fix

The diagnostic comes with a quick fix, *Name the default members '…', passing the last one the name as a String*, when the class the object is
declared as states every default member on the way. It writes the call the `!` stands for: `rs!Name` becomes `rs.Fields.Item("Name")`,
`rs![Unit price]` becomes `rs.Fields.Item("Unit price")`, and `!Name` in a `With` block becomes `.Fields.Item("Name")`. A name that is not an
identifier is written in brackets, as `_Default` is.
