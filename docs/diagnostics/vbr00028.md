# VBR00028 — Out of stack space

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The call stack is full.

MS-VBA run-time error 28; the numeric portion of the code is the error's number. This code is raised by [`ILetCoercionRuntimeSemanticsProvider`](../api/RDCore.Runtime.Semantics.LetCoercion.ILetCoercionRuntimeSemanticsProvider.html), [`RuntimeProcedureInvoker`](../api/RDCore.Runtime.Execution.RuntimeProcedureInvoker.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The call stack is full.|a procedure that calls itself with no end|Give the recursion a base case.|
