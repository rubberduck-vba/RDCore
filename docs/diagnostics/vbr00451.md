# VBR00451: Property let procedure not defined and property get procedure did not return an object

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A `Property Let` is not defined and the `Property Get` did not return an object.

MS-VBA run-time error 451; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 451` or `Error 451`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Property Let` is not defined and the `Property Get` did not return an object.|`x.P = 1` where `P` can only be read|Define the `Property Let`, or `Set` an object.|
