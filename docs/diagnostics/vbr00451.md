# VBR00451: Property let procedure not defined and property get procedure did not return an object

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A `Property Let` is not defined and the `Property Get` did not return an object.

MS-VBA run-time error 451; the numeric portion of the code is the error's number. This code is raised by `ProcedureExecutor`, `ScriptingCallProvider`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Property Let` is not defined and the `Property Get` did not return an object.|`x.P = 1` where `P` can only be read|Define the `Property Let`, or `Set` an object.|
|The enumeration member (`VB_UserMemId = -4`) of a `For Each` loop's collection returns `Nothing`.|`For Each v In h`, where `h`'s `NewEnum` property does `Set NewEnum = Nothing`|Return an enumerator from the member, such as `Set NewEnum = mItems.[_NewEnum]`.|
|A late-bound call gives arguments to a member of a `Scripting` object that takes none and returns no object.|`fso.GetFolder(p).Name(1)`, where `fso` is an `Object` that holds a `Scripting.FileSystemObject`|Call the member without arguments.|
