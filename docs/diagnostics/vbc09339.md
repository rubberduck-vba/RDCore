# VBC09339: Argument not optional

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A procedure that takes an argument is called without it: a function or a `Property Get` named without an argument list where its value is used, or an object whose default member takes an argument, used where a value is expected.

A function or a `Property Get` named without an argument list is called with no arguments. One that has a parameter that is neither `Optional` nor a `ParamArray` cannot be called so. Inside its own body, the name of a function or a `Property Get` is the value it returns.

Where a value is expected, an object stands for what its default member returns. A `Collection`'s default member is `Item`, which takes the key of the item it reads: a `Collection` has no value of its own to give, and neither has an object of any class whose default member takes an argument that is not `Optional`.

MS-VBA reports the same error: [Argument not optional](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/argument-not-optional-error-449). The same words are run-time error 449, which a call that leaves out an argument raises.

This code is raised by `BareFunctionReferenceStaticSemantics`, at the function's name; by `ObjectValueStaticSemantics`, at the object; and by the
checks of an assignment's target: a function named as the target of an assignment, or in an `Erase` statement, is called with no argument, and one
that takes an argument is the same error.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A function or a `Property Get` that takes an argument is named without one, where its value is used.|`s = Left`, `Debug.Print Mid`, `n = F + 1` with `Function F(ByVal a As Long)`|Give it its arguments: `s = Left(name, 1)`.|
|The object is assigned to a variable of a value type.|`Dim n As Long: n = New Collection`|Read an item: `n = items(1)`, or `n = items.Count`.|
|The object is an operand.|`s = "Total: " & items`|The same.|
|The object is passed to a parameter of a value type, or to a function that reads a value, such as `CStr`, `Abs` or `Len`.|`Debug.Print CStr(items)`|The same.|
|A function that takes an argument is named as the target of an assignment, or in an `Erase` statement.|`Left = "x"`, `Set Left = Nothing`, `Erase Left`|Assign a variable of your own.|

An object passed to a `Variant` - assigned to one, passed to a `ByVal x As Variant` parameter, or to a function such as `TypeName` - is passed as the object it is, and is not this error.
