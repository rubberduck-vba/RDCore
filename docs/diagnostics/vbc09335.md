# VBC09335 — Type-declaration character does not match declared data type

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A name is written with a type-declaration character (`%`, `&`, `^`, `!`, `#`, `@` or `$`) that is not the type it was declared as.

The character says the type of the name it is written on: `x$` is a `String`, `x%` an `Integer`. A name written with one is the identifier that was declared, and has the type that declaration gave it; if that is not the type the character says, the character is changing the type of a variable, which VBA does not allow.

MS-VBA reports the same error:
[Type-declaration character does not match declared data type](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/type-declaration-character-does-not-match-declared-data-type).

This code is raised by [SimpleNameExpressionStaticSemantics](../api/RDCore.SDK.Semantics.Static.Expressions.SimpleNameExpressionStaticSemantics.html), at the name and not at the statement it is in.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A variable declared with one character, written with another.|`Dim x$` … `x% = 42`|Write the name with the character it was declared with, or with none.|
|A variable declared `As` a type, written with the character of another.|`Dim x As String` … `x% = 42`|Write it with `$`, or with none.|
|A name that is declared by being used, written with two characters.|`y$ = "a"` … `y% = 1`|Use one type for the name.|

## Notes

A name written with no character never raises this: the declaration is the only thing that says its type. A member of the library that has a character in its name (`Left$`, `Environ$`) is not a name written with a character: it is looked for as written, and `Hex$` is a different member from `Hex`, with a different type.

Declaring one identifier twice in a procedure, with two characters or none (`Dim x$` and `Dim x%`), is a duplicate declaration (`VBC09303`), not this; see [**RD-VBAL §2.3.1.3** Name Resolution](../specs/rd-vbal.2.3.1.3.name-resolution.md).
