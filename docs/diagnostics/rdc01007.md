# RDC01007 — Host library not referenced

**Severity:** Error &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** [`DocumentModuleHostAnalyzer`](../api/RDCore.Diagnostics.Analyzers.DocumentModuleHostAnalyzer.html)

A module is the code of a document of a host RD-VBA knows - an Excel worksheet, say - and the project does not reference the host's library. The members of
the document's class are then no names of the module's code: `Range` and `Me.Range` in a worksheet's code name nothing, and are reported as such.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A document module whose host's library is not among the project's references.|`"Super": "ExcelWorksheet"`, and no reference to `Excel`|Add the reference to the `.rdproj`: `"References": [ { "Name": "Excel" } ]`.|

## Notes

With the reference, the module's code binds, and the module is reported as code that presumes its host:
[**RDC01005** Hosted document code](rdc01005.md) explains how to move it.
