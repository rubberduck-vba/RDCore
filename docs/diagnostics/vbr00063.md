# VBR00063 — Bad record number

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A record number is not valid.

MS-VBA run-time error 63; the numeric portion of the code is the error's number. This code is raised by `SessionFileChannels`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A record number is not valid.|`Get #1, 0, x`|Records are numbered from 1.|
