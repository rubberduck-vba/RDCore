# VBR00020 — Resume without error

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A `Resume` runs with no error to resume from.

MS-VBA run-time error 20; the numeric portion of the code is the error's number. This code is raised by [`ProcedureExecutor`](../api/RDCore.Runtime.Execution.ProcedureExecutor.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Resume` runs with no error to resume from.|`Resume Next` outside an error handler|Use `Resume` only in a handler.|
