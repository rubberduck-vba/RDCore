# VBR00055 — File already open

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A file is already open, or the file number is in use.

MS-VBA run-time error 55; the numeric portion of the code is the error's number. This code is raised by `SessionFileChannels`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A file is already open, or the file number is in use.|`Open` twice on `#1`|Close it first, or use `FreeFile`.|
