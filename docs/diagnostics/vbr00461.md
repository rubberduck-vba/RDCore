# VBR00461 — Method or data member not found

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A method or data member is not found.

MS-VBA run-time error 461; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 461` or `Error 461`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A method or data member is not found.|`c.Item("nosuch")` of a collection, a member a class lacks|Use a member that exists.|
