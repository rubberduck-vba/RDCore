# VBR00452 — Invalid ordinal

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An ordinal is not valid.

MS-VBA run-time error 452; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 452` or `Error 452`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An ordinal is not valid.|a `Declare` by an ordinal the library lacks|Use a valid one.|
