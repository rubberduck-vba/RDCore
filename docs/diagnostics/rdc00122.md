# RDC00122: Indexed unbound default member access

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `IndexedUnboundDefaultMemberAccessAnalyzer`

An argument list is given to a variable declared `As Object`.

The arguments go to the default member of the object it holds ([**RD-VBAL §5.6.13** Index Expressions](../specs/rd-vbal.5.6.13.index-expressions.md)),
which is known only when the code runs. An object whose class has no default member raises run-time error 438 (Object doesn't support this property or
method).

The finding is the whole expression.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An argument list given to an `Object`.|`Dim items As Object`<br>`first = items(1)`|Name the member: `first = items.Item(1)`; or declare the variable with its class.|
