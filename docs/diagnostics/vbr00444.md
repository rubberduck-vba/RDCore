# VBR00444 — Method not applicable in this context

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A method is called where it does not apply.

MS-VBA run-time error 444; the numeric portion of the code is the error's number. A UserForm's `Controls.Remove` raises it for a control the form's designer declared: only a control the program added at run time (`Controls.Add`) can be removed (Excel-measured).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|`Controls.Remove` is given a control of the form's designer, by its name or its position.|`Me.Controls.Remove "TextBox1"`|Hide the control instead (`TextBox1.Visible = False`), or remove only the controls the program added.|
