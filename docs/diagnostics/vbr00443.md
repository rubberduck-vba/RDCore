# VBR00443 — Automation object does not have a default value

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An Automation object has no default value.

MS-VBA run-time error 443; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 443` or `Error 443`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An Automation object has no default value.|`x = obj` where `obj` has no default member|Name a member.|
