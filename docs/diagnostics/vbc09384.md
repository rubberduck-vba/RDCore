# VBC09384: Only valid in object module

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A procedure of a standard module is declared `Friend`.

`Friend` makes a procedure of a class accessible to the code of its own project, and to no other project. A standard module's procedures have no such
access level: one is `Public`, accessible wherever its module is accessible, or `Private`, accessible within its module.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Sub` or a `Function` of a standard module is declared `Friend`.|`Friend Sub Reset()`|Declare it `Public` or `Private`, or move it to a class module.|
|A `Property Get`, `Let` or `Set` of a standard module is declared `Friend`.|`Friend Property Get Count() As Long`|Declare it `Public` or `Private`, or move it to a class module.|
