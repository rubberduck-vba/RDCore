# VBR00006 — Overflow

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A result does not fit the type it is computed in or assigned to.

MS-VBA run-time error 6; the numeric portion of the code is the error's number. This code is raised by [`BinaryArithmeticOperatorRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Operators.BinaryArithmeticOperatorRuntimeSemantics.html), [`BinaryRelationalOperatorRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Operators.BinaryRelationalOperatorRuntimeSemantics.html), [`InputListEvaluator`](../api/RDCore.Runtime.Execution.InputListEvaluator.html), [`LetCoercionRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Abstract.LetCoercionRuntimeSemantics.html), [`StdConversion`](../api/RDCore.Runtime.StdLib.StdConversion.html), [`StdFinancial`](../api/RDCore.Runtime.StdLib.StdFinancial.html), [`UnaryArithmeticOperatorRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Operators.UnaryArithmeticOperatorRuntimeSemantics.html), [`ValueConversionResult`](../api/RDCore.Runtime.Semantics.Conversion.ValueConversionResult.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A result does not fit the type it is computed in or assigned to.|`CInt(40000)`, `32767 + 1` as `Integer`|Use a wider type.|
