# VBR00449 — Argument not optional

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A required argument is not given.

MS-VBA run-time error 449; the numeric portion of the code is the error's number. This code is raised by [`RuntimeExpressionEvaluator`](../api/RDCore.Runtime.Semantics.RuntimeExpressionEvaluator.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A required argument is not given.|`Foo` where `Foo` takes one|Pass it.|
