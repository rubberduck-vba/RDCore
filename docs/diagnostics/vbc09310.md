# VBC09310 — Type mismatch

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A value is of a type that cannot be let-coerced to the type it is assigned to, passed as, or compared against.

MS-VBA reports the same error, at compile time and at run time: [Type mismatch](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/type-mismatch-error-13). The run-time error is [VBR00013](vbr00013.md).

This code is raised by [`StaticSemantics`](../api/RDCore.SDK.Semantics.Static.Abstract.StaticSemantics.html), [`SetCoercionStaticSemantics`](../api/RDCore.SDK.Semantics.Static.SetCoercionStaticSemantics.html), [`PrecompilerLiveBranchEvaluator`](../api/RDCore.Runtime.Semantics.Precompiler.PrecompilerLiveBranchEvaluator.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An operand or a value is of a type the operation or the target cannot take.|`Dim n As Long: n = New Collection`|Convert, or use the right type.|
|A conditional-compilation condition is not a number or a `Boolean`, or does not evaluate.|`#If "a" Then`, `#If 1 / 0 Then`|Write a number or a `Boolean` expression.|
