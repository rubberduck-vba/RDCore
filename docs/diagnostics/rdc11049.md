# RDC11049: Single-line If with no statement

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `EmptyIfBlockAnalyzer`

A line ends with `Then` and one or more colons, with no statement after them and no `Else`.

VB6 and MS-VBA read the line as a single-line `If` that does nothing: the lines after it run whatever the condition, and an `End If` after it is
[`VBC00047`](vbc00047.md).
[**MS-VBAL §5.4.2.9**](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/6b4fae50-5e47-4469-970b-a2b5a2b62e7a)
gives the line no reading, since a statement must follow the colon, and a block `If`
([**MS-VBAL §5.4.2.8**](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/17ff9b37-fbc8-491f-85b2-13c3a379acac))
ends its line right after `Then`. RD-VBA runs the line as VB6 does, and this warning marks it.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The lines after it were meant to run only when the condition is true.|`If found Then:` followed by `Debug.Print "A"`|Remove the colon, and close the block with `End If`.|
|The statement was meant to be on the same line.|`If found Then:` followed by `count = count + 1`|Move the statement after the colon: `If found Then: count = count + 1`, or after `Then` with no colon.|
|The line does nothing.|`If found Then:` left from an edit|Remove the line.|
