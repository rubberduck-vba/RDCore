# VBR00035 — Sub or Function not defined

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A call names a procedure that is not defined.

MS-VBA run-time error 35; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 35` or `Error 35`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A call names a procedure that is not defined.|a late-bound call to a name nothing declares|Declare it, or call what exists.|
