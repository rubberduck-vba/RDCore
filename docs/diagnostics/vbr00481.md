# VBR00481: Invalid picture

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A picture is not valid.

MS-VBA run-time error 481; the numeric portion of the code is the error's number. `LoadPicture` raises it for a file that holds no picture it reads.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The file is not a picture.|`Set p = LoadPicture("notes.txt")`|Load a bitmap, GIF, JPEG, PNG, icon, cursor or metafile.|
|The file is empty.|`Set p = LoadPicture("empty.bmp")`|Load a complete picture file.|

**RD-VBA addition:** a PNG loads as a bitmap (`Type` 1) and keeps its alpha channel. MS-VBA raises 481 for a PNG.
