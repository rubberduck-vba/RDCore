# VBR00481: Invalid picture

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A picture is not valid.

MS-VBA run-time error 481; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 481` or `Error 481`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A picture is not valid.|loading a file that is not a picture|Use a valid one.|
