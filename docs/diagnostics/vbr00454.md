# VBR00454 — Code resource not found

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A code resource is not found.

MS-VBA run-time error 454; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 454` or `Error 454`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A code resource is not found.|loading a missing code resource|Provide it.|
