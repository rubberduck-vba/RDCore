# VBC09317 — Invalid use of Me

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

`Me` is written where there is no object it could be.

`Me` is the object whose code is running, and a standard module has none ([**MS-VBAL §5.6.11** Instance Expressions](../specs/rd-vbal.5.6.11.instance-expressions.md)).

This code is raised by [`InstanceExpressionStaticSemantics`](../api/RDCore.SDK.Semantics.Static.Expressions.InstanceExpressionStaticSemantics.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|`Me` is written in a standard module.|`Debug.Print Me.Name` in `Module1`|Move the code to a class module, or name an object.|
