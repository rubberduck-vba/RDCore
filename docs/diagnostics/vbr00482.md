# VBR00482 — Printer error

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A printer error occurred.

MS-VBA run-time error 482; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 482` or `Error 482`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A printer error occurred.|a print to a printer that fails|See the printer.|
