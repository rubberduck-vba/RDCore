# VBR00076 — Path not found

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A path does not exist.

MS-VBA run-time error 76; the numeric portion of the code is the error's number. This code is raised by `SessionFileChannels`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A path does not exist.|`Open "nodir\x.txt" For Output As #1`|Create the directory first.|
