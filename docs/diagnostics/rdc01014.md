# RDC01014: Assigned ByVal parameter

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `AssignedByValParameterAnalyzer`

A procedure assigns one of its `ByVal` parameters.

A parameter passed by value is a copy of the argument ([**RD-VBAL §5.3.1.5** Parameter Lists](../specs/rd-vbal.5.3.1.5.parameter-lists.md)): assigning it
changes the copy, and the caller's variable keeps its value. A reader may expect the caller to see the change, or lose track of the value the procedure was given.

The value parameter of a `Property Let` or `Property Set` is passed by value even when it is declared `ByRef`
([**RD-VBAL §5.3.1.7** Property Declarations](../specs/rd-vbal.5.3.1.7.property-declarations.md)), and is reported too.

The finding is the name of the parameter.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `ByVal` parameter assigned in its procedure.|`Sub Work(ByVal count As Long)`<br>`    count = count + 1`<br>`End Sub`|Assign a local variable of its own instead (`Dim result As Long: result = count + 1`), or make it `ByRef` if the caller is meant to see the change.|
