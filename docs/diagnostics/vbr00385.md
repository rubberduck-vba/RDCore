# VBR00385 — Need property array index

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A property array needs an index.

MS-VBA run-time error 385; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 385` or `Error 385`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A property array needs an index.|`obj.Items = 1` for an array property|Give an index.|
