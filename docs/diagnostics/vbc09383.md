# VBC09383: There is no host application to evaluate the expression

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A name in brackets names nothing that is declared.

A name in brackets that the project declares, such as `[My Field]`, is that name. One that nothing declares is the text of an expression that a host
application evaluates: in Excel, `[A1]` is the cell `A1` of the active sheet. RD-VBA runs no host application, so nothing can evaluate the expression.
This is an error with or without `Option Explicit`, and the name never declares an implicit variable.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A name in brackets is read.|`x = [A1]`|Declare the name, or write the value it stands for.|
|A name in brackets is assigned.|`[A1] = 5`|Assign to a declared variable.|
|A name in brackets is printed.|`Debug.Print [A1]`|Print a declared variable or a value.|
|A name in brackets is the owner of a member access.|`x = [A1].Value`|Use an object variable that holds the object.|
