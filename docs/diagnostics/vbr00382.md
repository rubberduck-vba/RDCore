# VBR00382: Set not supported at runtime

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A property cannot be set at run time.

MS-VBA run-time error 382; the numeric portion of the code is the error's number. A control of a form raises it when a program assigns a property that
only a designer and the form's file set. `Err.Raise 382` and `Error 382` raise it too.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|On a Visual Basic 6.0 form, a late-bound assignment of a property that VB6 sets only at design time.|`Dim t As Object`, `Set t = Text1`, `t.MultiLine = True`|Set it in the designer, or in the form's file.|
|On an RDForms form, an assignment of a property that neither VB6 nor Microsoft Forms 2.0 lets a program set.|`Timer1.Left = 10`|Set it in the designer, or in the form's file.|

An RDForms form lets a program set what either library lets it set: `Text1.MultiLine = True` runs there, as it does on an MSForms UserForm.
