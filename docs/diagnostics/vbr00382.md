# VBR00382 — Set not supported at runtime

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A property cannot be set at run time.

MS-VBA run-time error 382; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 382` or `Error 382`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A property cannot be set at run time.|assigning a design-time-only property|Set it at design time.|
