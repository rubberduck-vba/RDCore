# VBC09303 — Duplicate declaration in current scope

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A name is declared more than once at one level of scope.

MS-VBA reports the same error: [Duplicate declaration in current scope](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/duplicate-declaration-in-current-scope). A type-declaration character is how a type is said and not a different name: `x$` and `x%` are both `x`.

This code is raised by [`DeclarationStaticSemanticsEvaluator`](../api/RDCore.SDK.Semantics.Static.DeclarationStaticSemanticsEvaluator.html), [`StatementStaticSemanticsEvaluator`](../api/RDCore.SDK.Semantics.Static.StatementStaticSemanticsEvaluator.html), [`ClassModuleEventSemantics`](../api/RDCore.SDK.Semantics.Static.ClassModuleEventSemantics.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A module declares a name twice, as the same kind of thing or not.|`Public Total As Long` and `Public Sub Total()`; two `Sub Main`|Rename or remove one.|
|A procedure declares a name twice: its parameters, variables and constants share one scope.|`Dim x$` and `Dim x%`|Rename or remove one.|
|A `#Const` is declared twice in a module.|`#Const Flag = 1` and `#Const Flag = 0`|Declare it once.|
