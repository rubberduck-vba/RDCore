# VBR00380 — Invalid property value

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A property is given a value it does not accept.

MS-VBA run-time error 380; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 380` or `Error 380`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A property is given a value it does not accept.|`obj.Size = -1` where the object refuses it|Set a value the property allows.|
