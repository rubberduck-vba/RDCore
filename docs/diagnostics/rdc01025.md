# RDC01025: Procedure not used

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `ProcedureNotUsedAnalyzer`

No code calls a `Sub`, a `Function` or a `Property`, except its own code.

A procedure that is never called does nothing for the program. It is often left over from code that changed. A procedure that calls itself (a recursion)
is not used by that call: something else has to call it first.

A `Private` procedure is counted over the code of its module, and a `Friend` one over every module of the project. A `Public` procedure is counted over
every module of the project where only the project's code can call it: in a program, a project that starts at its entry point (the procedure its
`.rdproj` names, or its `Sub Main`; see [RDC30001](rdc30001.md)) and is not a library.

These are not reported:

- a `Public` procedure of a library, or of a project with no entry point, which another project or the host that runs the project may call;
- a `Private` procedure whose name a string of the project writes (`Application.Run "Refresh"`, `OnAction`), which a host can call by its name;
- a `Private` procedure of a module that calls `CallByName` with a name no string gives;
- the entry point, a procedure that handles an event (`Class_Initialize`, `Button_Click`), and one that implements a member of an interface: the event or the
  interface calls them;
- a procedure that carries an annotation an extension of the platform declares as an entry point, such as a unit test's `'@TestMethod`: the extension
  calls it from outside the project.

A `Public` member of a class is not reported when an access bound late may name it (`o.Refresh`, with `o` declared `As Object`), when it is the default
member or the enumerator of its class, nor when the program calls `CallByName`.

The finding is the name of the procedure.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Private` procedure nothing calls.|`Private Sub Unused()`<br>`End Sub`|Remove it.|
|A procedure that only calls itself.|`Private Function Fact(ByVal n As Long) As Long`<br>`If n > 1 Then Fact = n * Fact(n - 1) Else Fact = 1`<br>`End Function`|Remove it, or call it where it was meant to be called.|
|A `Public` procedure of a program that nothing calls.|`Public Sub Refresh()`<br>`End Sub`|Remove it.|

## Quick fix

The finding comes with a quick fix, *Remove 'Unused'*. It removes the lines of the procedure, or of every accessor of the property, and the program does the
same. It is offered when nothing else, such as a comment after `End Sub`, is written on those lines.
