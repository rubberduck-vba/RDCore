# VBR00011 — Division by zero

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A divisor is zero.

MS-VBA run-time error 11; the numeric portion of the code is the error's number. This code is raised by [`BinaryArithmeticOperatorRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Operators.BinaryArithmeticOperatorRuntimeSemantics.html), [`StdFinancial`](../api/RDCore.Runtime.StdLib.StdFinancial.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A divisor is zero.|`1 / 0`, `5 \ 0`, `5 Mod 0`|Test the divisor first.|
