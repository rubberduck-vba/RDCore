# VBR00393 — Get not supported at runtime

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A property cannot be read at run time.

MS-VBA run-time error 393; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 393` or `Error 393`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A property cannot be read at run time.|reading a design-time-only property|Do not read it.|
