# VBR00393: Get not supported at runtime

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A property cannot be read at run time.

MS-VBA run-time error 393; the numeric portion of the code is the error's number. A control of a form raises it when a program reads a property that only a designer and the form's file
reach. `Err.Raise 393` and `Error 393` raise it too.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A read of a property that a running program cannot reach: a Menu's `Shortcut`, a Timer's `Left` and `Top`, a Data control's `Negotiate`.|`Debug.Print Timer1.Left`|Do not read it.|
