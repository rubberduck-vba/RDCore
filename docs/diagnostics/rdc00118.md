# RDC00118: Variant form of a String function

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `VariantStringFunctionAnalyzer`

A function of the VBA library that returns a `Variant` is called where the library has the same function returning a `String`: its name with a `$`.

`Left$` is functionally identical to `Left`, except that it returns a `String` rather than a `Variant`, and so are the other pairs of the library
(**MS-VBAL §6.1.2**). The `Variant` holds the same text, and code that assigns it to a `String` or passes it on converts it each time. The `$` form
says the result is text, and a `Null` argument is an error at the call rather than a `Null` result.

The functions reported are `Chr`, `ChrB`, `ChrW`, `Command`, `CurDir`, `Environ`, `Error`, `Format`, `Hex`, `Input`, `InputB`, `LCase`, `Left`,
`LeftB`, `LTrim`, `Mid`, `MidB`, `Oct`, `Right`, `RightB`, `RTrim`, `Space`, `Str`, `String`, `Trim` and `UCase`. `Date` and `Time` are not: the text
`Date$` and `Time$` return is not what `Date` and `Time` return.

The finding is the name of the function. The quick fix writes the `$` after it.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A function that returns a `Variant` gives a `String` its value.|`Dim initial As String`<br>`initial = Left(name, 1)`|Use the `$` form: `initial = Left$(name, 1)`.|
|A qualified call.|`Debug.Print VBA.UCase(code)`|`Debug.Print VBA.UCase$(code)`.|
