# VBR00447 — Object doesn't support current locale setting

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An object does not support the current locale setting.

MS-VBA run-time error 447; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 447` or `Error 447`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An object does not support the current locale setting.|a call with a locale the object lacks|Change the locale.|
