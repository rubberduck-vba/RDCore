# VBR00053 — File not found

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A file that is to be read or deleted does not exist.

MS-VBA run-time error 53; the numeric portion of the code is the error's number. This code is raised by `SessionFileChannels`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A file that is to be read or deleted does not exist.|`Open "x.txt" For Input As #1`, `Kill "x.txt"`|Check that it exists.|
