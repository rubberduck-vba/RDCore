# VBR00325 — Invalid format in resource file

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A resource file's format is not valid.

MS-VBA run-time error 325; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 325` or `Error 325`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A resource file's format is not valid.|loading a malformed resource|Fix the resource.|
