# VBR00460 — Invalid clipboard format

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A clipboard format is not valid.

MS-VBA run-time error 460; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 460` or `Error 460`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A clipboard format is not valid.|a paste of a format that is not|Use a valid format.|
