# RDC01016: Line label not used

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `LineLabelNotUsedAnalyzer`

No `GoTo`, `GoSub`, `Resume` or `On Error GoTo` of a procedure names one of its line labels.

A label belongs to its procedure, and only a jump of the procedure can reach it
([**RD-VBAL §5.4.1.1** Statement Labels](../specs/rd-vbal.5.4.1.1.statement-labels.md)). A label nothing jumps to is often left over from code that changed.

A line number is not reported: `Erl` reads the number of the line an error was raised on, so a line number may be there for that.

The finding is the label.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A line label that no jump names.|`Sub Work()`<br>`Retry:`<br>`    Debug.Print 1`<br>`End Sub`|Remove the label.|
