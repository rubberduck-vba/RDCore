# RDC01013: Parameter not used

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `ParameterNotUsedAnalyzer`

Nothing in a procedure refers to one of its parameters.

Every caller must still pass an argument for it, unless it is `Optional`, and a reader of the signature expects the procedure to use it.

A procedure whose signature is not its own to choose is not reported:

- an implementation of an interface member, and a handler of an event, which repeat the declaration they match;
- a `Declare`, which states what the library takes, and an `Event`;
- a `Public` member of a class module, which may be a member of an interface another class module implements
  ([**RD-VBAL §5.2.4.2** Implements Directive](../specs/rd-vbal.5.2.4.class-module-declarations.md#5242-implements-directive)).

The finding is the name of the parameter.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A parameter nothing in the procedure refers to.|`Sub Work(ByVal used As Long, ByVal unused As Long)`<br>`    Debug.Print used`<br>`End Sub`|Remove the parameter and the arguments of its callers, or use it.|
