# RDC01013: Parameter not used

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `ParameterNotUsedAnalyzer`

Nothing in a procedure refers to one of its parameters.

Every caller must still pass an argument for it, unless it is `Optional`, and a reader of the signature expects the procedure to use it.

A procedure whose signature is not its own to choose is not reported:

- an implementation of an interface member, and a handler of an event, which repeat the declaration they match;
- a `Declare`, which states what the library takes, and an `Event`;
- a `Public` member of a class that a module of the project implements, or that is exposed to other projects (`VB_Exposed = True`): it may be a member of an
  interface another class module implements
  ([**RD-VBAL §5.2.4.2** Implements Directive](../specs/rd-vbal.5.2.4.class-module-declarations.md#5242-implements-directive)).

A parameter of an interface member or of an event is reported where the member has implementations, or the event has handlers, in the project, and none of
them uses its own parameter at that position: the argument passed for it reaches no code. The quick fix removes the parameter of an interface member from
every implementation too. An event's parameter has no quick fix: remove it from the event and its handlers by hand. A class exposed to other projects is
left out, since a project that references this one may implement it or handle its events.

> [!NOTE]
> **Not implemented.** Whether a project that references this one implements an exposed class is not checked: a `Public` member of an exposed
> class is never reported.

The finding is the name of the parameter.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A parameter nothing in the procedure refers to.|`Sub Work(ByVal used As Long, ByVal unused As Long)`<br>`    Debug.Print used`<br>`End Sub`|Remove the parameter and the arguments of its callers (the quick fix does both), or use it.|
|A parameter of an interface member that no implementation uses.|`Public Sub Area(ByVal size As Double)` in `IShape`; `IShape_Area` in `Ring` and `Square` never reads `size`|Remove the parameter from the member, its implementations and its callers (the quick fix does all three), or use it.|
|A parameter of an event that no handler uses.|`Public Event Changed(ByVal oldValue As Long)`; no `_Changed` handler reads `oldValue`|Remove the parameter from the event, its handlers and its `RaiseEvent` statements, or use it.|
