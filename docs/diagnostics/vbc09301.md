# VBC09301 — Ambiguous name detected

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

An identifier names more than one declaration at the same level of scope, so it has to be qualified.

MS-VBA reports the same error: [Ambiguous name detected](https://learn.microsoft.com/office/vba/language/reference/user-interface-help/ambiguous-name-detected).

This code is raised by [`ScopeTreeSymbolResolver`](../api/RDCore.SDK.Model.Symbols.ScopeTreeSymbolResolver.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|Two projects or modules that the code can see declare the same name.|`Total` declared as a public variable in two referenced libraries|Qualify the name with the module or project that declares it: `Lib1.Total`.|
