# RDC11033: Reserved name that MS-VBA accepts

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `DeclarationNameDivergenceAnalyzer`

A declaration has a name that the specification reserves, and MS-VBA compiles it all the same.

A declaration is named with an identifier that is not a reserved identifier
(**MS-VBAL §3.3.5.2**).
`Date`, `DoEvents` and `CDec` are reserved names, so no Enum member can have them. MS-VBA compiles an Enum member with one of these names
(recorded in Excel 16), where it refuses every other reserved name.

RD-VBA does as MS-VBA does: the member is declared, and this warning stands for what the specification says.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An Enum member named `Date`, `DoEvents` or `CDec`.|`Private Enum Field` ... `Date` ... `End Enum`|Give the member another name, such as `DateField`.|

A name written in brackets (`[Date]`) is a foreign name (**MS-VBAL §3.3.5.3**), which the specification allows, and is not reported.
