# VBC09389: Module directive stated differently

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

Two parts of a module state one of its directives differently.

Each part of a module ([**RD-VBAL §5.1**](../specs/rd-vbal.5.1.module-body-structure.md#modules-of-parts)) may state whether other projects see the
module, whether they can create its objects, whether a class has a default instance, and what the module is for. A module file states them with its
attributes and `Option Private Module`; a block states them with the words of its header (`Public`, `Private`, `Creatable`) and the
`'@PredeclaredId` and `'@ModuleDescription` annotations. The parts that state a directive state it the same way.

The error is at each statement that differs from the first part's. The module does not load, none of its parts does, and a program that has it does
not run.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|Two headers state the visibility differently.|`Public Partial Class Account` in one file, `Private Partial Class Account` in another|Write the visibility in one header only.|
|A class file is not creatable, and a block says it is.|`Attribute VB_Creatable = False` in `Account.cls`, and `Partial Creatable Class Account`|Delete `Creatable` from the header, or change the attribute.|
|A standard module file is private, and a block says it is public.|`Option Private Module` in `Helpers.bas`, and `Public Partial Module Helpers`|Delete `Public` from the header.|
|A class file has no default instance, and a block gives it one.|`Attribute VB_PredeclaredId = False` in `Account.cls`, and `'@PredeclaredId` in a `Partial Class Account` block|Delete the annotation, or change the attribute.|
|Two parts describe the module differently.|`'@ModuleDescription("Sums.")` in `Helpers.bas`, and `'@ModuleDescription("Totals.")` in a `Partial Module Helpers` block|Describe the module in one part.|
