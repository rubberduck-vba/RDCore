# VBR00321 — Invalid file format

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A file's format is not valid.

MS-VBA run-time error 321; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 321` or `Error 321`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A file's format is not valid.|loading a file that is not the format|Use a valid file.|
