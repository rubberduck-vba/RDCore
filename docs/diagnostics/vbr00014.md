# VBR00014 — Out of string space

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A string would be longer than the platform allows.

MS-VBA run-time error 14; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 14` or `Error 14`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A string would be longer than the platform allows.|`String(2147483647, "a")`|Build less.|
