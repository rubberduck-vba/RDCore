# VBR00003 — Return without GoSub

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A `Return` runs with no `GoSub` to return to.

MS-VBA run-time error 3; the numeric portion of the code is the error's number. This code is raised by [`ProcedureExecutor`](../api/RDCore.Runtime.Execution.ProcedureExecutor.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Return` runs with no `GoSub` to return to.|`Return` in a procedure whose `GoSub` never ran|Reach a `Return` only through a `GoSub`.|
