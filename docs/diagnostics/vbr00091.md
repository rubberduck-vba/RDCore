# VBR00091 — Object variable or With block variable not set

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An object is used that is not set to anything.

MS-VBA run-time error 91; the numeric portion of the code is the error's number. This code is raised by [`LetAssignmentEvaluator`](../api/RDCore.Runtime.Semantics.Statements.LetAssignmentEvaluator.html), [`ProcedureExecutor`](../api/RDCore.Runtime.Execution.ProcedureExecutor.html), [`RuntimeExpressionEvaluator`](../api/RDCore.Runtime.Semantics.RuntimeExpressionEvaluator.html), [`VBObjectLetCoercionRuntimeSemantics`](../api/RDCore.Runtime.Semantics.LetCoercion.VBObjectLetCoercionRuntimeSemantics.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An object is used that is not set to anything.|`x.Name` when `x` is `Nothing`, `For Each` over `Nothing`|`Set` the variable before using it.|
