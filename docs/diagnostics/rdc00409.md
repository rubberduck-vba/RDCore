# RDC00409: Public field

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `EncapsulatePublicFieldAnalyzer`

A class module declares a `Public` variable.

A `Public` variable of a class module is a member of its objects ([**MS-VBAL §5.2.3.1** Module Variable Declaration Lists](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/0f9113df-fd9c-485a-9583-fdb0e9d68e1b)).
Any code that holds an object of the class can assign it any value of its type, and the class has no say. A `Property Get` and a `Property Let` (or
`Set`) over a `Private` variable give the class a place to check the value, or to refuse it.

The finding is the name of the variable.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Public` variable of a class module.|`Public Name As String`|Make the variable `Private`, and give the class a `Property Get Name` and a `Property Let Name`.|
