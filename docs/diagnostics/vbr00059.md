# VBR00059 — Bad record length

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A record is not the length the file was opened with.

MS-VBA run-time error 59; the numeric portion of the code is the error's number. This code is raised by [`FileStatementRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Statements.FileStatementRuntimeSemantics.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A record is not the length the file was opened with.|`Put #1, , x` with `Len` that does not fit|Open with the `Len` the record has.|
