# VBR00383 — Set not supported (read-only property)

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A property is read-only.

MS-VBA run-time error 383; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 383` or `Error 383`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A property is read-only.|assigning a read-only property|Do not assign it.|
