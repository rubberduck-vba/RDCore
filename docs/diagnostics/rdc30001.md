# RDC30001: No entry point

**Severity:** Error &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core, the builder) &nbsp;·&nbsp;
**Raised by:** `rdc run` and `rdc build`, before the program runs or is written

A program starts at its entry point: a script, a `Public Sub Main()` or a `Sub Main(ParamArray Args())` of a standard module, or the procedure the build
section of the `.rdproj` names. This workspace has none, so there is nothing to run and nothing to build. `rdc run` exits with code `2`, and `rdc build`
writes no program. The reason, and this code, are on standard error.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|No standard module declares a `Sub Main`.|The workspace's procedures are all called `Start`, or `Main` is in a class module|Add a `Public Sub Main()` to a standard module, or name the procedure to start at in the build section.|
|The build section names an entry point that no standard module declares.|`"entryPoint": "Program.Start"`, and `Program` has no `Start`|Name a procedure the module declares, or declare it.|
|The module file run is one the `.rdproj` of its folder lists, and the module is neither a script nor declares a `Sub Main`.|`rdc run Tools.bas`, and `Tools` declares only `Backup` and `Restore`|Run the project's folder, or the file of a module that is a script or declares a `Sub Main`.|
|The project is a library.|`"outputType": "Library"`|A library is not run: run the program that references it.|
