# RDC11052: Argument of an incompatible class

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `ArgumentOfAnIncompatibleClassAnalyzer`

An argument declared as a class is given to a parameter declared as another class, and no object of the argument's class can be an object of the
parameter's.

The argument is assigned to the parameter as a `Set` would assign it: by value, and by reference too where the argument is not a variable of the
parameter's own class. The parameter takes an object of its class, or of a class that implements it, and the call raises run-time error 13 (Type
mismatch) for any other. When neither class implements the other and no class of the workspace implements both, every object the argument can hold is
refused. VBA compiles the call, and raises error 13 every time it is made with an object.

```vb
Public Sub Draw(ByVal shape As IShape)
End Sub

Dim item As New Account      ' Account does not implement IShape
Draw item                    ' error 13
```

This is what Microsoft Office VBA does, as [**MS-VBAL §5.3.1.11**][arguments] and [**MS-VBAL §5.5.2.2.1**][set-coercion] state it.
The cases [RDC11051](rdc11051.md) leaves out are left out here too, as is a variable given by reference to a parameter of its own class.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The class is meant to be usable as the interface.|`Draw item`|Add `Implements IShape` to the class `Account`.|
|The wrong argument is given.|`Draw item`|Give an object of a class that implements `IShape`.|
