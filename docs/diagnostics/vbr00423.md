# VBR00423 — Property or method not found

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A property or method is not found.

MS-VBA run-time error 423; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 423` or `Error 423`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A property or method is not found.|`obj.NoSuch` on an object that reports so|Use a member the object has.|
