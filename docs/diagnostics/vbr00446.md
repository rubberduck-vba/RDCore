# VBR00446 — Object doesn't support named arguments

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An object does not support named arguments.

MS-VBA run-time error 446; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 446` or `Error 446`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An object does not support named arguments.|`obj.Method Name:=1` on an object that cannot|Pass positionally.|
