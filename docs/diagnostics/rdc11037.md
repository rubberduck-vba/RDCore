# RDC11037: Non-breaking space in a name

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `NonBreakingSpaceInNameAnalyzer`

A declared name has a non-breaking space (U+00A0) in it.

A non-breaking space looks like an ordinary space, so the name reads as two words. MS-VBAL has no identifier with such a character in it
(**MS-VBAL §3.3.5**).
MS-VBA compiles it as part of the name, and so does RD-VBA. The same name typed with an ordinary space is not the same name, or not a name at all.

Code copied from a web page often has such spaces.

The names are those of variables, constants, procedures, parameters and line labels. The finding is the name; the message shows it with an ordinary space.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A name with a non-breaking space between two of its letters.|`Dim my Value As Long`, the space a U+00A0|Remove the space, or retype it as part of a name with no space (`myValue`).|
