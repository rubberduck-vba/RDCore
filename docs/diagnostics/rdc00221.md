# RDC00221: VBA.Array ignores Option Base

**Severity:** Hint &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `QualifiedArrayOptionBaseAnalyzer`

A call of the `VBA` library's `Array` function, qualified as `VBA.Array(...)`, is made in a module that states `Option Base 1`.

The unqualified `Array(...)` returns an array whose lower bound is the module's `Option Base`. The library's function, called by its qualified name,
always returns an array with a lower bound of 0 ([**RD-VBAL §6.1.2.13** Hidden Module](../specs/rd-vbal.6.1.2.13.hidden-module.md)). In a module with
`Option Base 1`, the two give arrays of different bounds from the same arguments.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|`VBA.Array` in a module with `Option Base 1`.|`Option Base 1` … `items = VBA.Array(1, 2, 3)`|Read the array from `LBound(items)`, or call the unqualified `Array` for an array that starts at 1.|
