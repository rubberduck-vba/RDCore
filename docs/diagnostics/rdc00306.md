# RDC00306 — Obsolete Let statement

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** [`ObsoleteLetStatementAnalyzer`](../api/RDCore.Diagnostics.Analyzers.ObsoleteLetStatementAnalyzer.html)

An assignment is written with the `Let` keyword.

`Let x = 1` and `x = 1` are the same assignment ([**MS-VBAL §5.4.3.8** Let Statement](../specs/rd-vbal.5.4.3.8.let-statement.md)): the keyword is optional, and nobody writes it any
more. The diagnostic is an opinion of the analyzer and not a condition of the language: both are legal.

The finding is the keyword. It is a suggestion because removing it does not change what the statement does.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An assignment is written with `Let`.|`Let total = 1`|Remove the keyword: `total = 1`.|
