# RDC01024: Default project name

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `DefaultProjectNameAnalyzer`, on the project's `.rdproj`

A project is named `VBAProject`, the name MS-VBA gives a new project. The name says nothing of what the project is.

The name is compared without regard to case. The finding is the project's name in its `.rdproj`, or the start of the file when the file names no project.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The project file names the project `VBAProject`.|`"Name": "VBAProject"`|Give the project a name of its own: `"Name": "NavalBattle"`.|
