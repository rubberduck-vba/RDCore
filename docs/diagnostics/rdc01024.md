# RDC01024: Default project name

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `DefaultProjectNameAnalyzer`, on the project's `.rdproj`

A project is named `VBAProject`, the name MS-VBA gives a new project. The name says nothing of what the project is.

The name is compared without regard to case. The diagnostic is reported at the project's name in its `.rdproj`, or at the start of the file when the file
names no project. A project its file does not name is named after its folder, and `VBAProject` when the folder's name is not a valid identifier.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The project file names the project `VBAProject`.|`"Name": "VBAProject"`|Give the project a name of its own: `"Name": "Invoicing"`.|
|The project file names no project, and its folder's name is `VBAProject` or is not a valid identifier.|A `My Macros` folder whose `.rdproj` has no `"Name"`|Name the project in its `.rdproj`: `"Name": "Invoicing"`.|
