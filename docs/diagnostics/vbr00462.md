# VBR00462 — The remote machine does not exist or is unavailable

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The remote server machine does not exist or is unavailable.

MS-VBA run-time error 462; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 462` or `Error 462`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The remote server machine does not exist or is unavailable.|`CreateObject("X.Y", "nosuchhost")`|Name a machine that is.|
