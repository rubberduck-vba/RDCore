# VBR00422 — Property not found

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A property is not found.

MS-VBA run-time error 422; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 422` or `Error 422`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A property is not found.|`obj.NoSuch` on an object that reports so|Use a property the object has.|
