# VBR00054 — Bad file mode

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An operation is not valid for the mode a file was opened in.

MS-VBA run-time error 54; the numeric portion of the code is the error's number. This code is raised by [`FileStatementRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Statements.FileStatementRuntimeSemantics.html), [`StdHidden`](../api/RDCore.Runtime.StdLib.StdHidden.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An operation is not valid for the mode a file was opened in.|`Print #1, x` on a file opened `For Input`|Open the file for what you do with it.|
