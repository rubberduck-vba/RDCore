# RDC00123: Bang notation

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `BangNotationAnalyzer`

A dictionary access, `items!key`, of an object of a known class.

The `!` gives the name after it, as a `String`, to the default member of the object
([**RD-VBAL §5.6.14** Dictionary Access Expressions](../specs/rd-vbal.5.6.14.dictionary-access-expressions.md)): `items!key` is `items.Item("key")`.
It looks like a member of the object, and is a string the compiler does not check.

The finding is the whole expression.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `!` name.|`price = fields!Price`|Name the member and pass the string: `price = fields.Item("Price")`.|
