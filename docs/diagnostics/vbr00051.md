# VBR00051 — Internal error

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The interpreter has no implementation for what the program does. This is a gap in the platform, not an error of the program.

MS-VBA run-time error 51; the numeric portion of the code is the error's number. This code is raised by [`ILetCoercionRuntimeSemanticsProvider`](../api/RDCore.Runtime.Semantics.LetCoercion.ILetCoercionRuntimeSemanticsProvider.html), [`OperatorRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Abstract.OperatorRuntimeSemantics.html), [`RuntimeSemanticsEvaluationResult`](../api/RDCore.SDK.Runtime.Shared.RuntimeSemanticsEvaluationResult.html), [`VBObjectLetCoercionRuntimeSemantics`](../api/RDCore.Runtime.Semantics.LetCoercion.VBObjectLetCoercionRuntimeSemantics.html), `StatedErrors`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The interpreter has no implementation for what the program does. This is a gap in the platform, not an error of the program.|a library member declared and not written yet|Report it; the platform is incomplete.|
