# RDC01012: Variable not assigned

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `VariableNotAssignedAnalyzer`

A variable is read, and nothing assigns it: no statement, and no procedure it is passed to.

A variable starts with the default value of its declared type: `0` for a number, `""` for a `String`, `False` for a `Boolean`, `Empty` for a `Variant`
([**RD-VBAL §5.2.3.1.4** Variable Type Declarations](../specs/rd-vbal.5.2.3.module-declarations.md#52314-variable-type-declarations)). A variable that is never
assigned always reads as that value, which is rarely what the code means: an assignment is often missing, or made to another name.

Only the variables that nothing outside the module can refer to are counted: a local variable, and a `Private` variable of the module.

A procedure assigns a variable passed to it only through a `ByRef` parameter that it assigns, or passes on `ByRef` to a procedure that does
([**MS-VBAL §5.3.1.11** Procedure Invocation Argument Processing](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/1fb9af32-fc48-4c4f-998a-ed8047048ca5)).
The procedures of the module, called by name or through `Me`, are followed that way, a procedure that calls itself included. A variable passed `ByRef` to
any other procedure is not reported: one of another module or of a library, a `Declare`d procedure, a procedure called through an object variable, or the
handlers of an event raised with `RaiseEvent`.

These variables can get what they hold in other ways than an assignment, and are not reported: an array, a variable re-dimensioned with `ReDim`, a
`WithEvents` variable, and a variable of an object type or of a user-defined type.

The finding is the name of the variable.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A variable read and never assigned.|`Dim total As Long`<br>`Debug.Print total`|Assign it before it is read, or write the value it always has (`Debug.Print 0`).|
|A variable passed where nothing assigns it.|`Dim total As Long`<br>`Show total`, with `Sub Show(ByVal n As Long)`|Assign it before the call, or pass the value it always has.|
