# RDC00213: Line continuation between keywords

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `LineContinuationBetweenKeywordsAnalyzer`

A keyword of two words, such as `End If` or `Exit Sub`, is split over several lines with a line continuation.

A line continuation is white space ([**MS-VBAL §3.3** Lexical Tokens](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/848bd0b2-e453-4f50-a42a-452eb0923c6d)),
so it can stand between the two words of a keyword, and the code is legal VBA. A keyword split this way is hard to read: `End` at the end of one line reads as an
`End` statement.

The finding is the line continuations of the keyword. A line continuation in a comment continues the comment, and is not reported.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A line continuation between the words of a keyword.|`End _`<br>`If`|Write the keyword on one line: `End If`.|
