# VBR00440 — Automation error

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An Automation operation failed.

MS-VBA run-time error 440; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 440` or `Error 440`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An Automation operation failed.|a call into a server that failed|See the server's error.|
