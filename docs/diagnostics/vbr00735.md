# VBR00735 — Can't save file to TEMP

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A file cannot be saved to the temporary directory.

MS-VBA run-time error 735; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 735` or `Error 735`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A file cannot be saved to the temporary directory.|a save with no room there|Free space.|
