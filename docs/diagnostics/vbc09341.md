# VBC09341 — Can't assign to read-only property

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](../api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A property that can only be read is assigned with `Let`.

The class declares a `Property Get` of that name and no `Property Let`: the property can be read, and there is nothing that writes it.

MS-VBA reports the same error, with the same message (recorded in Excel).

This code is raised by [`StatementStaticSemanticsEvaluator`](../api/RDCore.SDK.Semantics.Static.StatementStaticSemanticsEvaluator.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Property Get` with no `Property Let`.|`c.Value = 1`|Add a `Property Let Value` to the class, or assign what the property reads.|

## Notes

Through an object declared `As Object` or `Variant`, the class is not known until the code runs: the assignment compiles, and raises error 451 when it runs.
