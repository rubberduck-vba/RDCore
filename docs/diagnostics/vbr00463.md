# VBR00463: Class not registered on local machine

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A class is not registered on the local machine.

MS-VBA run-time error 463; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 463` or `Error 463`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A class is not registered on the local machine.|`CreateObject` of an unregistered class|Register it.|
