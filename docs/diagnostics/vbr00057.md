# VBR00057 — Device I/O error

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

The device reported an input or output failure.

MS-VBA run-time error 57; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 57` or `Error 57`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The device reported an input or output failure.|a write to a failing device|Retry, or use another device.|
