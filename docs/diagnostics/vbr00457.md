# VBR00457 — This key is already associated with an element of this collection

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A key is already used by an element of the collection.

MS-VBA run-time error 457; the numeric portion of the code is the error's number. This code is raised by [`IStdCollectionClass`](../api/RDCore.SDK.Runtime.Abstract.StdLib.IStdCollectionClass.html), `StdCollection`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A key is already used by an element of the collection.|`c.Add 1, "k"` twice|Use a distinct key.|
