# RDC00413: Module variable used in one procedure

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `MoveFieldCloserToUsageAnalyzer`

A variable of the module is used in one procedure only. It can be declared in that procedure, where a reader sees it with the code that uses it.

A variable of the module keeps its value from one call to the next, and a local does not. When the procedure counts on that, declare the local `Static`.

A variable declared `Private` or with `Dim` is reported. A `Public` one is reported where only the project's code can use it:

- in a program, a project that starts at its entry point (a `Sub Main`, see [RDC30001](rdc30001.md)) and is not a library;
- in a standard module that is `Option Private Module`.

A `Public` variable of a standard module can be used by a procedure of another module, which can declare it. A `Public` variable of a class is
reported only when that procedure is the class's own: another module uses it as a member of an object. A `Public` variable of a class that an access bound
late names, and every one when the program calls `CallByName`, are not reported.

A `WithEvents` variable is not reported: the procedures that handle its events use it too.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The procedure sets the variable before it reads it.|`Private mTotal As Long`, used only in `Sum`, which starts with `mTotal = 0`|Declare it in `Sum`: `Dim total As Long`.|
|The procedure keeps the value between calls.|`Private mCalls As Long`, used only in `Log`, as `mCalls = mCalls + 1`|Declare it `Static` in `Log`: `Static calls As Long`.|
|A `Public` variable of a program that one procedure of another module uses.|`Public gCount As Long` in `Globals`, used only in `Tally` of `Program`|Declare it in `Program.Tally`.|
