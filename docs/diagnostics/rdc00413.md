# RDC00413: Module variable used in one procedure

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `MoveFieldCloserToUsageAnalyzer`

A variable of the module is used in one procedure only. It can be declared in that procedure, where a reader sees it with the code that uses it.

A variable of the module keeps its value from one call to the next, and a local does not. When the procedure counts on that, declare the local `Static`.

A variable declared `Private` or with `Dim` is reported. A `Public` one is reported where only the project's code can use it:

- in a program, a project that starts at its entry point (the procedure its `.rdproj` names, or its `Sub Main`; see [RDC30001](rdc30001.md))
  and is not a library;
- in a standard module that is `Option Private Module`.

A `Public` variable of a standard module that one procedure of another module uses can be declared in that procedure. A `Public` variable of a class
is reported only when the procedure that uses it is the class's own: another module uses it as a member of an object.
A `Public` variable of a class that an access bound late names, and every one when the program calls `CallByName`, are not reported.

A `WithEvents` variable is not reported: the procedures that handle its events use it too.

The code action at the finding is the Move Closer To Usage refactoring. It declares the variable in the procedure that uses it, in its module or in
another one, where a use written `Globals.gCount` becomes `gCount`. An editor with a refactoring dialog asks whether to declare it `Static` or `Dim`.
Any other editor is offered the edit with `Static`, which keeps the value between calls. In a class, each object keeps its own value of the `Static`
local, as it does of the variable of the class
([**RD-VBAL §5.4.3.1** Local Variable Declarations](../specs/rd-vbal.5.4.3.1.local-variable-declarations.md)). A variable of a standard module
moved into a member of a class would have one value for each object instead of one for the program: that move is offered only through the dialog.

A `Public` variable of a class stays where it is declared: it is a member of each object of the class. At its finding, the code action is offered
disabled, with the reason.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The procedure sets the variable before it reads it.|`Private mTotal As Long`, used only in `Sum`, which starts with `mTotal = 0`|Declare it in `Sum`: `Dim total As Long`.|
|The procedure keeps the value between calls.|`Private mCalls As Long`, used only in `Log`, as `mCalls = mCalls + 1`|Declare it `Static` in `Log`: `Static calls As Long`.|
|A `Public` variable of a program that one procedure of another module uses.|`Public gCount As Long` in `Globals`, used only in `Tally` of `Program`|Declare it in `Program.Tally`.|
