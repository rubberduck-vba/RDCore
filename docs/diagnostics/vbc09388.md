# VBC09388: Module part of another kind

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBC` (static semantics / abstract syntax tree) &nbsp;·&nbsp;
**Source metadata:** [`VBCompileErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBCompileErrorInfo.html)

A part of a module is not of the module's kind.

A `Partial Class` or `Partial Module` block is a part of the module of its name, in its own file or in another file of the project
([**RD-VBAL §5.1**](../specs/rd-vbal.5.1.module-body-structure.md#modules-of-parts)). The module is of the kind of its plain part: its module file, or
its block without `Partial`. When every part is `Partial`, the module is of its first part's kind. The parts of a class module are `Class` parts, and
the parts of a standard module are `Module` parts.

The error is at each part of another kind. The module does not load, none of its parts does, and a program that has it does not run.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Partial Class` block of a standard module.|`Helpers.bas`, and `Partial Class Helpers` in another file|Write `Partial Module Helpers`, or give the class another name.|
|A `Partial Module` block of a class module.|`Account.cls`, and `Partial Module Account` in another file|Write `Partial Class Account`.|
|`Partial` blocks of both kinds, and no plain part.|`Partial Class Account` in one file, `Partial Module Account` in another|Write every part with one kind.|
|A `Partial Class` block of a document module.|`Sheet1.doccls`, and `Partial Class Sheet1` in another file|Write the code in the document module.|
