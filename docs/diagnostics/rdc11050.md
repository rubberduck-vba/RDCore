# RDC11050: Let to an object with no default member

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `LetToAnObjectWithNoDefaultMemberAnalyzer`

A `Let` statement assigns a value to a target declared as a class that has no default member: a variable, an element of an array, or a
`Property Get` with no `Property Let` or a function that returns an object of that class.

A value assigned to an object is assigned to its default member. An object of a class with none has nothing to take the value. VBA compiles the
statement, and raises a run-time error every time it runs:

- error 438 (Object doesn't support this property or method) when the target holds an object;
- error 91 (Object variable or With block variable not set) when it holds `Nothing`.

```vb
Dim item As New Plain     ' Plain: Public Tag As Long, no default member
item = 5                  ' error 438
shelf.Item = 5            ' Property Get Item() As Plain, no Property Let: error 438
```

This is what Microsoft Office VBA does.
[**MS-VBAL §5.4.3.8**](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/ce2a98d4-2625-4cb7-982c-5c58e568cd18)
states error 438, for `Nothing` as well.
A target declared `Object` or `Variant` is not reported: the class of the object it holds is known only when the code runs.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The value is meant for a member of the object.|`item = 5`|Name the member: `item.Tag = 5`.|
|The value is meant for the property.|`shelf.Item = 5`|Give the property a `Property Let`.|
|The object itself is meant.|`item = other`, both declared `As Plain`|`Set` it: `Set item = other`.|

## Quick fix

The diagnostic comes with a quick fix, *Assign the object itself, with Set*, when the value is `Nothing` or an object declared as the target's class,
and the target is a variable or a property with a `Property Set`: `item = other` becomes `Set item = other`. It changes what the code does.
