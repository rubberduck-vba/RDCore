# RDC00211: On Error GoTo -1

**Severity:** Hint &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `OnErrorGoToMinusOneAnalyzer`

A procedure holds an `On Error GoTo -1` statement.

`On Error GoTo -1` ends the error being handled, and keeps the error-handling policy as it is. MS-VBAL does not document it; MS-VBA compiles it, and so does
RD-VBA ([**RD-VBAL §5.4.4.1** On Error Statement](../specs/rd-vbal.5.4.4.1.on-error-statement.md)). A reader can rarely tell what it does.

A `Resume` also ends the handler, and says where the procedure goes on. `On Error GoTo 0` turns error handling off.

The finding is the statement.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An `On Error GoTo -1` statement.|`Handler:`<br>`    On Error GoTo -1`|End the handler with `Resume`, `Resume Next` or `Resume <label>`.|
