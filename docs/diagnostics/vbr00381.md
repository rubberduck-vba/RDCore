# VBR00381 — Invalid property array index

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A property array index is not valid.

MS-VBA run-time error 381; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 381` or `Error 381`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A property array index is not valid.|`obj.Items(99)`|Index within the array.|
