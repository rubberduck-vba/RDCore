# VBR00047 — Too many DLL application clients

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A `Declare`d library has more clients than it supports.

MS-VBA run-time error 47; the numeric portion of the code is the error's number. The runtime semantics of the platform do not raise this yet; a workspace raises it with `Err.Raise 47` or `Error 47`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Declare`d library has more clients than it supports.|`Declare` call of a library at its limit|Release clients.|
