# RDC01011: Variable not used

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `VariableNotUsedAnalyzer`

Nothing reads the value of a variable: nothing refers to it, or only its assignments do.

A variable that is never read does nothing for the program. It is often left over from code that changed, or a name typed where another was meant. When it
is assigned, the message says so: the value assigned to it is lost.

A local variable and a `Private` variable of the module (`Dim` or `Private`) are counted over the code of the module. A `Public` variable is counted over
every module of the project where only the project's code can use it:

- in a program, a project that starts at its entry point (the procedure its `.rdproj` names, or its `Sub Main`; see [RDC30001](rdc30001.md))
  and is not a library;
- in a standard module that is `Option Private Module`.

A `Public` variable of a library, or of a project with no entry point, may be read by another project or by the host that runs it, and is not reported. Nor
is a variable of a class that an access bound late names (`o.Tag`, with `o` declared `As Object`), nor any variable of a class when the program calls
`CallByName`. A `WithEvents` variable is used by the events it handles, and the control variable of a `For` or `For Each` loop by the loop: neither is
reported.

A procedure with an error is not analyzed completely, and its local variables are not reported. A variable of the module is still counted when
no procedure with an error writes its name: a procedure refers to a variable by its name, and one that does not name it does not use it. A `Public` variable
is counted the same way, over the project: when no procedure of the project with an error writes its name.

The finding is the name of the variable.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A variable nothing refers to.|`Dim unused As Long`|Remove it.|
|A `Public` variable of a program, or of a class of a program, that nothing refers to.|`Public Tag As String`|Remove it.|
|A variable that is assigned and never read.|`Dim total As Long`<br>`total = 42`|Remove it and its assignments, or use its value where it was meant to be used.|

## Quick fix

A variable nothing refers to comes with a quick fix, *Remove the declaration of 'unused'*. It removes the lines of the declaration, and the program does the
same. It is offered when the statement declares no other name and nothing else is written on its lines (no comment, label or other statement), and when no
`ReDim` names the variable: without the declaration, the `ReDim` would declare an array of its own. A variable that is assigned has no quick fix, because its
assignments would remain.
