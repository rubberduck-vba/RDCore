# VBR00424 — Object required

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

An object is required where a value is given.

MS-VBA run-time error 424; the numeric portion of the code is the error's number. This code is raised by [`BinaryRelationalOperatorRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Operators.BinaryRelationalOperatorRuntimeSemantics.html), [`LetCoercionRuntimeSemantics`](../api/RDCore.Runtime.Semantics.Abstract.LetCoercionRuntimeSemantics.html), [`RuntimeExpressionEvaluator`](../api/RDCore.Runtime.Semantics.RuntimeExpressionEvaluator.html), [`SetCoercionRuntimeSemantics`](../api/RDCore.Runtime.Semantics.SetCoercion.SetCoercionRuntimeSemantics.html).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An object is required where a value is given.|`Set x = 1`, `x.Name` when `x` is not an object|Use an object.|
