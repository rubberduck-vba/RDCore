# VBR00075 — Path/File access error

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A path or file cannot be accessed as asked.

MS-VBA run-time error 75; the numeric portion of the code is the error's number. This code is raised by `SessionFileChannels`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A path or file cannot be accessed as asked.|`MkDir` of a path that is a file|Use a path that can be.|
